# Federation Report Schema Foundation

Wave M-5 creates one reporting language for Mental Smile Federation.

This foundation does not create PDF, Excel, exports, UI, dashboards, charts,
Firestore, Firebase, collections, or writes.

## Report Language

Every report should use the same federation structure:

```text
Federation Report
-> Department Variant
```

Supported families:

- Residential reports
- Commercial reports
- Operational reports
- Strategic reports
- Constitutional reports
- Archive reports
- Monitoring reports

## Report Structure

`FederationReportSchema` contains:

- header
- metadata
- executive summary
- signals
- aggregates
- trends
- risks
- opportunities
- recommendations
- human analysis
- AI analysis
- constitutional alignment
- archive code
- retention class
- archive eligibility
- report version

## Header

`FederationReportHeader` contains:

- report id
- report code
- report type
- report category
- department id
- Arabic department name
- English department name
- report prefix
- created at
- period
- version

## Metadata

`FederationReportMetadata` contains:

- generated by
- reviewed by
- approved by
- retention class
- archive eligibility
- classification

These are labels only. No permissions are implemented.

## Sections

Foundation sections:

- `ExecutiveSummarySection`
- `SignalsSection`
- `AggregatesSection`
- `TrendsSection`
- `RisksSection`
- `OpportunitiesSection`
- `RecommendationsSection`
- `HumanAnalysisSection`
- `AIAnalysisSection`
- `ConstitutionalAlignmentSection`

Sections use AR/EN localized text from the start.

## Classification

`ReportClassification` supports:

- `public`
- `internal`
- `restricted`
- `constitutional`
- `owner_only`

## Periods

`ReportPeriod` supports:

- `daily`
- `weekly`
- `monthly`
- `quarterly`
- `annual`
- `custom`

## Meeting Packs

`MeetingPackSchema` contains:

- pack id
- meeting date
- reports
- executive summary
- strategic notes

No meeting UI or workflow is introduced.

## Archive Compatibility

Every federation report schema supports:

- archive code
- retention class
- archive eligibility
- report version

## Visual Identity

`DepartmentVisualIdentity` contains:

- department id
- color token
- icon key
- report stripe color
- label style key

No UI rendering is introduced.

## Localization

Report text models support Arabic and English through `LocalizedText`.

## Constitutional Boundary

Federation Reports must not accept sources from:

- `booking_requests`
- `bookingRequests`
- `sessionRatings`
- payment proof
- payout states
- assignment states
- session lifecycle
- admin lifecycle

The report boundary delegates source rejection to
`ForbiddenSignalSourceGuard`.
