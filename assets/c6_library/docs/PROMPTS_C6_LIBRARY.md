# C6 Library Assets — Prompt Sheet (Style matches C5)

Global style rules:
- Theme: "Modern Pharaoh" (Ancient Egypt motifs) + subtle futuristic AI glow.
- Palette: warm parchment/papyrus base, muted golds, deep teal accents, minimal neon.
- Clean, minimal, premium UI asset look.
- NO text baked into images (we render text in Flutter).
- Prefer transparent background for icons/badges/buttons/logos.
- Soft shadows only if needed; keep crisp edges.

Recommended sizes:
- Category icons: 512x512 PNG transparent.
- Badges: 512x256 PNG transparent.
- Buttons: 1024x320 PNG transparent (optional; can be vector-like).
- Logo mark: 512x512 PNG transparent.
- Wordmark: 1400x400 PNG transparent.
- Hero: 1920x800 PNG (can be non-transparent).
- States: 1400x1000 PNG (can be non-transparent).
