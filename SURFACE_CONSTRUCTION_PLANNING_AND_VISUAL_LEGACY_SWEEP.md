# Surface Construction Planning And Visual Legacy Sweep

## Purpose

Bundle G creates construction blueprints for the first federation rooms and adds visual legacy sweep language.

It does not create UI, widgets, pages, Firebase writes, Firestore collections, automation, notifications, route deletion, or asset deletion.

## Client Blueprint

The Client Room construction blueprint defines:

- Personal Signals
- Tool Frames
- Saved Destinations
- Guidance

It includes:

- sections
- cards
- counters
- guidance areas
- signal consumption areas

The blueprint is signal-first and does not use old lifecycle visuals as construction sources.

## Monitoring Blueprint

The Monitoring Room construction blueprint defines:

- Residential
- Commercial
- Observatory

It includes:

- monitoring sections
- aggregate cards
- aggregate counters
- report blueprint references

The monitoring blueprint consumes aggregate and observatory concepts only.

## Archive Blueprint

The Archive Room construction blueprint defines:

- archive packages
- archive cards
- archive reports
- sovereign archive

The archive blueprint keeps owner sovereign material separate from general federation packages.

## Cross Surface Functions

Cross-surface function sweep tracks new federation function overlap across new surfaces.

Classifications:

- duplicate
- overlap
- shared
- needs_merge
- unique

This sweep is new-function to new-function. It is separate from legacy/new conflict tracking.

## Visual Asset Audit

Visual asset audit tracks:

- card images
- backgrounds
- banners
- illustrations
- icons
- embedded text assets

The registry records asset type, surface, linked function, and audit status.

## Visual Legacy Sweep

Visual legacy sweep classifies visuals as:

- legacy_visual
- legacy_text_embedded
- legacy_background
- legacy_banner
- needs_replacement
- safe

This makes old visual spirit visible before construction starts.

## Replacement Planning

Replacement planning follows this rule:

Old Function Removed

Linked Visual Removed

Card Marked Needs Federation Visual

No visual asset is deleted in this foundation.

## Missing Visual Markers

Missing visual markers mean:

No Image

Check Card

Check Function

Check Replacement

Missing visuals are construction warnings, not runtime errors.

## Constitutional Boundaries

The visual boundary prevents these names from becoming new visual foundation names:

- booking_banner
- session_banner
- payment_banner
- admin_background
- legacy_visual_surface

The foundation may mention these terms only as forbidden boundary examples.
