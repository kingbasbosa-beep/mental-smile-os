# Crisis-Safe Copy Test Plan

## Purpose

Define review checks for static crisis-safe support copy.

## Validate

- Copy is Arabic-first, calm, short, and non-shaming.
- Copy does not diagnose, promise rescue, guarantee emergency intervention, or claim therapy.
- Copy encourages trusted human support and local emergency help when there is immediate danger.
- Copy avoids panic language, guilt, manipulation, and clinical certainty.

## Deferred

- Localization QA.
- Legal review.
- Clinical/safety review.
- Platform review.
- In-app placement review.
