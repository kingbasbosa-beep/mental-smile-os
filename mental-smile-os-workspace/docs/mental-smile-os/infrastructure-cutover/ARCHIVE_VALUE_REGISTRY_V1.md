# Archive Value Registry V1

Status: ARCHIVE_VALUE_DEFINED

Archive is reserved for material with future rollback, legal, technical, educational, or lineage value. Junk cache is not archive.

## Keep As Archive Value

| Item | Value | Status |
| --- | --- | --- |
| Old infrastructure evidence cards | Explain previous Firebase and Android identity | PRESERVE |
| Rollback cards | Enable reversal if cutover fails | PRESERVE |
| Google services backup | Allows Android Firebase config rollback | PRESERVE |
| Infrastructure cutover reports | Explain decision trail | PRESERVE |
| Historical docs with lessons | Preserve project learning | PRESERVE |

## Not Archive Value

| Item | Reason |
| --- | --- |
| `.firebase/` cache | Generated local hosting cache with no lasting knowledge value |
| Build output | Reproducible generated output |
| Duplicate temporary generated files | No unique source or lesson value |

## Archive Rule

Archive only reusable knowledge, rollback evidence, or legally/technically useful records.
