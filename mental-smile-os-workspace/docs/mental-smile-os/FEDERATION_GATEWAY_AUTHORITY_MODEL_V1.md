# Federation Gateway Authority Model V1

Status: ACTIVE_GATEWAY_AUTHORITY_MODEL
Prompt Asset: PROMPT_ASSET_033

## Gateway May

- Receive.
- Classify.
- Count.
- Summarize.
- Forward.
- Buffer.

## Gateway May Not

- Mutate Foreign Zone Data.
- Authorize.
- Govern.
- Execute.
- Make content decisions.
- Run recommendation logic.
- Perform AI decisions.
- Own users.
- Make business decisions.

## Gateway Authority Rule

Gateways are federation transport and observation infrastructure.

They are not governing bodies.
