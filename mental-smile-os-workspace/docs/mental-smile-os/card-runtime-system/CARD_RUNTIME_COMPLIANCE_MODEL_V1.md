# CARD_RUNTIME_COMPLIANCE_MODEL_V1

Status: REGISTERED

## Compliance Questions

Every runtime card must answer:

- Does the card have a birth prompt?
- Does the card have an owner?
- Does the card have a registry binding?
- Does the card have validation status?
- Is the runtime consumer approved?
- Is the card active, frozen, retired, or archived?
- Does runtime consume without mutating authority?
- Does distribution preserve card version?
- Does archive preserve lineage?

## Compliance Status

- COMPLIANT
- COMPLIANT_WITH_WARNINGS
- BLOCKED
- CONSTITUTIONAL_VIOLATION
- UNKNOWN

## Violations

- Orphan card.
- Unregistered runtime card.
- Runtime mutation of governance card.
- Active use of retired card.
- Card replacement without supersession.
- Card clone without new identity.
