# CARD_RECREATION_MODEL_V1

Status: REGISTERED

## Recreation Purpose

Card recreation rebuilds a card from evidence, lineage, and approved reconstruction notes.

## Recreation Inputs

- Source card record.
- Registry entry.
- Ownership record.
- Archive snapshot.
- Birth prompt.
- Birth signal.
- Recreation prompt or reconstruction notes.

## Recreation Outputs

- Recreated Card ID or version.
- Recreated registry entry.
- Updated ownership.
- Updated validation status.
- Updated archive snapshot.

## Forbidden Recreation

- Recreating from memory without evidence.
- Recreating from runtime code alone.
- Recreating without owner.
- Recreating without registry.
- Recreating retired card as active without approval.
