# Zone To Firebase Boundary Map V1

Status: ZONE_FIREBASE_BOUNDARY_MAP
Prompt Asset: PROMPT_ASSET_045

## Purpose

Map Mental Smile City Generation 1 zones to future Firebase boundary responsibilities.

## Boundary Map

| Zone | Future Firebase Boundary | Ownership Principle |
| --- | --- | --- |
| APP_ROOM_ZONE | App identity, app room signals, app screen state packages | App data remains app-owned and gateway-mediated. |
| LIBRARY_WEB_ZONE | Library content, tools, research, resource cards | Library owns content and discovery assets. |
| PROVIDER_REGISTRATION_WEB_ZONE | Provider onboarding, credentials, private review documents | Registration owns private onboarding evidence. |
| PROVIDER_PUBLIC_WEB_ZONE | Approved provider public profiles and public assets | Public zone consumes approved public packages only. |
| CENTER_REGISTRATION_WEB_ZONE | Center onboarding, documents, partnership and contract preparation | Registration owns private center evidence. |
| CENTER_PUBLIC_WEB_ZONE | Approved center public profiles and public assets | Public zone consumes approved public packages only. |
| OWNER_ZONE | Constitutional approval and evolution records | Owner authority must remain audited. |
| MONITORING_ZONE | Health, signal, gateway, continuity visibility | Monitoring observes and escalates only. |
| STRATEGIC_INTELLIGENCE_ZONE | Strategic summaries, analysis, recommendations | Strategic recommends and does not execute. |
| SMART_ARCHIVE_ZONE | Snapshots, clone packages, historical records, recovery assets | Archive stores and restores only. |

## Cross-Zone Rule

No Firebase boundary may permit direct cross-zone mutation.

Cross-zone transfer requires:

Zone Gateway -> Signal Pipe -> Target Zone Gateway.
