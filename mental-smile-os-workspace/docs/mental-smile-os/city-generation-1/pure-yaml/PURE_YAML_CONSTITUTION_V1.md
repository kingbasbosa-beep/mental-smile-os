# Pure YAML Constitution V1

Status: PURE_YAML_DOCTRINE
Prompt Asset: PROMPT_ASSET_045
Latest YAML Implementation Plan Prompt: PROMPT_ASSET_054

## Purpose

Define the constitutional rules for future YAML asset and configuration references inside Mental Smile OS.

This document does not edit YAML, pubspec.yaml, localization YAML, runtime config, or build configuration.

## YAML Principles

- YAML must reference only active OS assets.
- Old asset names remain source evidence only.
- No unused asset paths.
- No duplicate old/new asset paths.
- No deprecated placeholders.
- No temporary asset entries without expiry.
- No legacy splash, home, or client-room assets unless renamed and registered.
- Every YAML asset entry must map to an asset card, ownership card, recreation prompt, zone, screen or district, and status.

## Required Mapping

Every future YAML entry must answer:

- Which asset card owns this?
- Which ownership card governs rights?
- Which recreation prompt can rebuild it?
- Which zone owns it?
- Which screen or district consumes it?
- What is its active status?

## Boundary

Pure YAML doctrine is a parent package for future implementation.

No YAML file is modified by STEP 020.
