# Zone Asset YAML Boundary Map V1

Status: ZONE_ASSET_BOUNDARY_MAP
Prompt Asset: PROMPT_ASSET_045

## Purpose

Define which zone may own future YAML asset references.

## Boundary Map

| Zone | Asset Boundary |
| --- | --- |
| APP_ROOM_ZONE | App Surface screen assets and room visual packages. |
| LIBRARY_WEB_ZONE | Library district content, tool, research, resource, accessibility, recovery, and family assets. |
| PROVIDER_REGISTRATION_WEB_ZONE | Registration-only provider onboarding assets and private review document references. |
| PROVIDER_PUBLIC_WEB_ZONE | Approved provider public profile assets. |
| CENTER_REGISTRATION_WEB_ZONE | Registration-only center onboarding, partnership, and contract preparation assets. |
| CENTER_PUBLIC_WEB_ZONE | Approved center public profile and service display assets. |
| OWNER_ZONE | Constitutional approval and owner governance assets. |
| MONITORING_ZONE | Monitoring visibility assets. |
| STRATEGIC_INTELLIGENCE_ZONE | Strategic report assets. |
| SMART_ARCHIVE_ZONE | Snapshot, clone package, and recovery asset references. |

## Cross-Boundary Rule

An asset may be referenced by another zone only through an approved card package.

Ownership remains with the source zone.
