# Provider Public Web Zone Boundary Model V1

Status: ACTIVE_BOUNDARY_MODEL
Zone ID: PROVIDER_PUBLIC_WEB_ZONE
Prompt Asset: PROMPT_ASSET_040
Field Parity Prompt: PROMPT_ASSET_041

## Does

- Displays approved public provider profiles conceptually.
- Supports provider discovery.
- Supports service visibility.
- Supports public contact pathways.
- Supports trust display.

## Does Not

- Collect registration data.
- Mutate onboarding records.
- Read private registration documents.
- Control provider registration.
- Own credential submission.

## Transfer Rule

All transfer must pass through gateways and approved card packages.

## Field Boundary

Every public display field must have a declared source field and approved package source.

Provider Public Web Zone may not keep inactive, deprecated, duplicate, or unmapped public profile fields.
