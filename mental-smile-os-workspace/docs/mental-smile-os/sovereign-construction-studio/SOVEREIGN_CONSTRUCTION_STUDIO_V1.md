# Sovereign Construction Studio V1

Status: ACTIVE_PRACTICAL_ROOM
System: Mental Smile OS
Creation basis: Owner Decision
Room purpose: build approved constitutional packages from inside the project
Runtime effect: none

## 1. Identity

Sovereign Construction Studio is the practical construction workspace used to build future Mental Smile OS domains from inside the project after constitutional approval.

It is not Technical Operations, Maintenance Department, Legal Department, Monitoring, Tool Center, Archive Department, Residential Domain, or runtime operations.

## 2. Purpose

Sovereign Construction Studio exists to work from inside Mental Smile OS using approved sovereign construction tools.

It builds approved constitutional packages. It does not maintain, repair, deploy, monitor technical health, approve legality, or perform runtime maintenance. Those responsibilities belong to future authorities only if created later.

## 3. Allowed Powers

Sovereign Construction Studio may:

- Receive approved construction packages.
- Use registered construction tool references.
- Build project artifacts when a package is approved.
- Prepare construction outputs for Owner review.
- Request runtime verification through the approved verification workspace.

## 4. Forbidden Powers

Sovereign Construction Studio may not:

- Create Residential Domain in this step.
- Create Technical Operations.
- Create Maintenance Department.
- Create Legal Department.
- Create Monitoring.
- Change Firebase in this step.
- Change code in this step.
- Deploy, maintain, repair, or monitor runtime health.
- Treat tool access as domain authority.

## 5. Registered Tool References

- Owner / ChatGPT strategic architecture workspace.
- Codex construction workspace.
- Android Studio runtime verification workspace.
- GitHub source control workspace.
- Firebase console workspace.
- Google Play Console publishing workspace.
- Local project workspace.
- Mental Smile Core source repository reference.

## 6. Construction Boundary

Every construction action requires an approved construction package, related prompt lineage, related guide/card/signal records, and Owner review boundary.
