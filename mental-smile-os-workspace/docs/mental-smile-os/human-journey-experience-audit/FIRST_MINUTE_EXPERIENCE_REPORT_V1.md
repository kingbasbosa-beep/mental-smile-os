# First Minute Experience Report V1

Result: FIRST_MINUTE_REVIEW_COMPLETE

## First Minute: What a New Visitor Understands

A new visitor can understand that Mental Smile OS is an Arabic-first mental health discovery and support ecosystem. The public README and public landing explain the safety boundary well: not a clinic, not diagnosis, not therapy, not emergency, not booking/payment.

That is the strongest part of the first minute.

## First Minute: What Happens in Practice

| Surface | Experience | Status |
| --- | --- | --- |
| README | Strong public explanation, WHO source, release candidate status, safety boundaries. | STRONG |
| public-landing | Arabic-first public presentation with safety and official links. | STRONG |
| Splash/Login | Runtime has splash and login routes. Splash can lead to login or portal. | PARTIAL |
| Home/Menu | Menu provides paths into support, library, specialists, centers, and rooms. | PARTIAL |
| App Portal | Public portal routes exist, but some are skeleton-like. | PARTIAL |
| Showcase docs | Useful for reviewers, but not ideal as first human experience. | SUPPORTING |

## First Minute Strengths

- The mission is emotionally clear.
- Safety boundaries are unusually explicit.
- Arabic-first identity is visible.
- The tone is calm, not exploitative or over-medicalized.
- The project has enough structure to feel serious.

## First Minute Friction

- The visitor sees too many doors: README, landing, portal, splash, login, showcase, docs.
- The runtime path is less clear than the public story.
- It is not obvious which journey a client, family member, provider, or center should start with.
- Some public surfaces still feel like foundation pages rather than a finished service.

## First Minute Human Question

The visitor's likely question is:

"This is promising, but where do I start?"

## Recommended First-Minute Fix

Create one visible journey selector:

- I need support
- I am supporting a family member
- I am in recovery
- I want to learn
- I am a provider
- I represent a center

Each option should lead to one clear route and show safety boundaries before any sensitive action.
