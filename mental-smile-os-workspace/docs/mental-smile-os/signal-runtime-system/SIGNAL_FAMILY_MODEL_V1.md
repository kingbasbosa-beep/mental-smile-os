# SIGNAL_FAMILY_MODEL_V1

Status: REGISTERED

## Purpose

Signal families classify operational events so gateways, monitoring, archive, and strategic intelligence can handle packages without owning source authority.

## Core Families

| Signal Family | Purpose |
|---|---|
| REGISTRATION_SIGNALS | Identity, onboarding, registration state. |
| ROOM_ACTIVITY_SIGNALS | App room activity and navigation. |
| TOOL_SELECTION_SIGNALS | Tool selection and tool-interest activity. |
| NOTIFICATION_SIGNALS | Notification and announcement activity. |
| PROFILE_SHORTCUT_SIGNALS | Public profile shortcut interactions. |
| RESEARCH_DESK_SIGNALS | Provider research desk activity. |
| MOTIVATION_NOTE_SIGNALS | Motivation note selection/update activity. |
| EXIT_ACTION_SIGNALS | Room exit activity. |
| ASSISTANT_USAGE_SIGNALS | Assistant surface usage. |
| CONTENT_DISCOVERY_SIGNALS | Library content discovery activity. |
| TOOL_DISCOVERY_SIGNALS | Tool catalog discovery activity. |
| RESEARCH_DISCOVERY_SIGNALS | Research district discovery activity. |
| RESOURCE_DISCOVERY_SIGNALS | Resource and directory activity. |
| MONITORING_SIGNALS | Observability and health activity. |
| STRATEGIC_SUMMARY_SIGNALS | Strategic summaries and analysis inputs. |
| ARCHIVE_SNAPSHOT_SIGNALS | Archive snapshots and historical preservation. |
| EMERGENCY_CONTINUITY_SIGNALS | Capsule and emergency exchange continuity events. |

## Family Rule

No signal may move through the federation without a registered signal family.
