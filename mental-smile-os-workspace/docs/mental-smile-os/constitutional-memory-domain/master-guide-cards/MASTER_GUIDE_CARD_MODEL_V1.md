# Master Guide Card Model V1

Status: ACTIVE_MEMORY_MODEL
Domain: Constitutional Memory Domain
Memory area: master-guide-cards

## 1. Purpose

Master Guide Card Model defines the structure for future purified cards before Master Guide placement.

## 2. Required Fields

| Field | Requirement |
| --- | --- |
| Card ID | Stable identifier. |
| Card Name | Card name. |
| Card Type | Doctrine, guide, registry, signal, descendant, UI, localization, ownership, or other approved type. |
| Parent Guide | Guide reference. |
| Birth Prompt | Prompt that rebuilt the card. |
| Birth Authority | Authority that permitted card creation. |
| Source Candidate | Source candidate reference. |
| Classification | Use, rebuild, remove, not relevant, or missing-create-new outcome. |
| Registry Entry | Registry reference. |
| Lineage Status | Lineage status. |
| Validation Status | Validation status. |

## 3. Boundary

No Master Guide cards are created in this step.
