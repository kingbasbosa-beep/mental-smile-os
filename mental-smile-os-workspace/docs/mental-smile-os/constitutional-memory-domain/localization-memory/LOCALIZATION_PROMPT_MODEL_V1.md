# Localization Prompt Model V1

Status: ACTIVE_MEMORY_MODEL
Domain: Constitutional Memory Domain
Memory area: localization-memory

## 1. Purpose

Localization Prompt Model preserves prompts used to generate or purify localization terms.

## 2. Required Fields

| Field | Requirement |
| --- | --- |
| Prompt ID | Stable prompt identifier. |
| Term Scope | Term family or context. |
| Prompt Text | Prompt or prompt reference. |
| Language Direction | Arabic-first, English-support, bilingual, or other approved direction. |
| Avoid Rules | Forbidden language, tone, or legacy terminology. |
| Output Use | Intended localization use. |
| Version | Prompt version. |
| Related Term Cards | Term card references. |
| Lineage Status | Lineage status. |
| Validation Status | Validation status. |

## 3. Boundary

This model does not write localization runtime files.
