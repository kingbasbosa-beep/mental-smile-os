# Term Card Model V1

Status: ACTIVE_MEMORY_MODEL
Domain: Constitutional Memory Domain
Memory area: localization-memory

## 1. Purpose

Term Card Model defines how future purified localization terms are preserved.

## 2. Required Fields

| Field | Requirement |
| --- | --- |
| Term ID | Stable term identifier. |
| Arabic Term | Arabic-first text. |
| English Term | English text. |
| Context | UI, route, support, provider, marketplace, accessibility, or other approved context. |
| Allowed Usage | Where the term may appear. |
| Forbidden Usage | Where the term may not appear. |
| Replacement Terms | Approved replacements. |
| Source Candidate | Source evidence reference. |
| Owner | Custodian or authority boundary. |
| Lineage Status | Lineage status. |
| Validation Status | Validation status. |

## 3. Forbidden States

- Term without Arabic-first review.
- Term without context.
- Legacy term copied directly.
- Term without lineage or validation.
