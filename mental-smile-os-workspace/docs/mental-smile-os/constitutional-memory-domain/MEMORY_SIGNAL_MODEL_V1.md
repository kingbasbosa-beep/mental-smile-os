# Memory Signal Model V1

Status: ACTIVE_CONSTITUTION
Domain: Constitutional Memory Domain
Signal authority: Memory Validation Unit for memory integrity signals only

## 1. Signal Boundary

Memory signals describe continuity state. They do not authorize domains, govern source meaning, create roadmaps, or approve expansion.

## 2. Allowed Signals

| Signal ID | Signal Name | Meaning | Allowed Effect |
| --- | --- | --- | --- |
| MEMORY_SIGNAL_001 | LINEAGE_ESTABLISHED | A constitutional memory lineage chain is traceable. | Mark memory lineage intact. |
| MEMORY_SIGNAL_002 | LINEAGE_BROKEN | A lineage chain has a missing, invalid, or contradictory segment. | Require memory repair or DNA review if constitutional. |
| MEMORY_SIGNAL_003 | MEMORY_GAP_DETECTED | Required continuity evidence is missing. | Block memory validation until resolved. |
| MEMORY_SIGNAL_004 | SUPERSESSION_RECORDED | Replacement or supersession has been recorded with prior and next memory IDs. | Preserve replacement chain. |
| MEMORY_SIGNAL_005 | MEMORY_VALIDATED | Memory asset passed custody, registry, lineage, and separation checks. | Mark memory asset validated. |

## 3. Emission Requirements

Every memory signal must include:

- Signal ID.
- Signal name.
- Memory ID.
- Trigger condition.
- Continuity finding.
- Related DNA signal, if any.
- Action boundary.

## 4. Signal Prohibitions

Memory signals may not:

- Create domains.
- Authorize expansion.
- Decide what must exist next.
- Validate source authority.
- Replace DNA signals.
- Convert source repository artifacts into active OS structures.

## 5. DNA Escalation Rule

When a memory signal exposes a constitutional question, Constitutional Memory Domain must send evidence to DNA Vault. DNA Vault decides whether a DNA signal is required.
