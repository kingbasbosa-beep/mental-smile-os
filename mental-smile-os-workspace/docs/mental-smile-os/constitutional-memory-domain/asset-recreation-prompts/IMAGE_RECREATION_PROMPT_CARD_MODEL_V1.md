# Image Recreation Prompt Card Model V1

Status: ACTIVE_MEMORY_MODEL
Domain: Constitutional Memory Domain
Memory area: asset-recreation-prompts

## 1. Purpose

Image Recreation Prompt Card Model defines how prompts for regenerating images are preserved.

## 2. Required Fields

| Field | Requirement |
| --- | --- |
| Prompt ID | Stable prompt identifier. |
| Asset ID | Related image asset. |
| Asset Name | Image asset name. |
| Asset Type | Image, icon, background, illustration, or other approved type. |
| Prompt Text | Recreation prompt or prompt reference. |
| Style Rules | Visual style constraints. |
| Negative Prompt / Avoid Rules | Forbidden visual elements. |
| Output Use | Intended use. |
| Version | Prompt version. |
| Related UI Asset | UI asset card reference. |
| Related Ownership Card | Ownership card reference. |
| Lineage Status | Lineage status. |
| Validation Status | Validation status. |

## 3. Boundary

No image is generated by this model.
