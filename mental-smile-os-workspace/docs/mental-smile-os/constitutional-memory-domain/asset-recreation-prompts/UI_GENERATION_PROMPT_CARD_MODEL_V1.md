# UI Generation Prompt Card Model V1

Status: ACTIVE_MEMORY_MODEL
Domain: Constitutional Memory Domain
Memory area: asset-recreation-prompts

## 1. Purpose

UI Generation Prompt Card Model defines how prompts for generating UI components or visual UI systems are preserved.

## 2. Required Fields

| Field | Requirement |
| --- | --- |
| Prompt ID | Stable prompt identifier. |
| Asset ID | Related UI asset or component. |
| Asset Name | UI asset name. |
| Asset Type | Component, button, card, dashboard visual, route visual, or other approved type. |
| Prompt Text | Generation prompt or prompt reference. |
| Style Rules | UI style constraints. |
| Negative Prompt / Avoid Rules | Forbidden UI behavior or visual language. |
| Output Use | Intended use. |
| Version | Prompt version. |
| Related UI Asset | UI asset card reference. |
| Related Ownership Card | Ownership card reference. |
| Lineage Status | Lineage status. |
| Validation Status | Validation status. |

## 3. Boundary

No UI is generated by this model.
