# Guide Birth Rules V1

Status: ACTIVE_MEMORY_RULES
Domain: Constitutional Memory Domain
Applies to: constitutional guide assets

## 1. Foundational Rule

Every constitutional guide must be traceable. No guide may exist as a constitutional object without:

- Birth Prompt.
- Birth Authority.
- Birth Lineage.
- Registry Entry.
- Validation Status.

## 2. Birth Sequence

```text
Prompt
-> Birth Authority
-> Guide Asset
-> Guide Registry Entry
-> Memory Lineage
-> Memory Validation
-> Eligible Parent For Cards
```

## 3. Required Guide Birth Evidence

Every guide birth must preserve:

- Who created this.
- Why it was created.
- Which prompt created it.
- Which authority approved it.
- Which registry tracks it.
- Which cards may derive from it.
- Which signals reference it.
- Which descendants consume it.

## 4. Forbidden Birth Outcomes

The following are constitutionally invalid:

- Guide Without Birth Prompt.
- Guide Without Registry Entry.
- Guide Without Lineage.
- Guide Without Validation.
- Guide With Unknown Birth Authority.
- Orphan Guide.

## 5. Memory Integration

Every guide must preserve inside Constitutional Memory Domain:

- Birth Prompt.
- Birth Authority.
- Birth Justification.
- Birth Lineage.
- Registry Entry.
- Validation Status.

## 6. Boundary

Guide birth rules define traceability and parentage only. They do not create domains, authorize expansion, create strategic planning, or grant governance authority.
