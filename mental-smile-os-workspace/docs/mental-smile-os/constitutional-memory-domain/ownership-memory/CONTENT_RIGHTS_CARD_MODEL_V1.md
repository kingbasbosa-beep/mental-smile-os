# Content Rights Card Model V1

Status: ACTIVE_MEMORY_MODEL
Domain: Constitutional Memory Domain
Memory area: ownership-memory

## 1. Purpose

Content Rights Card Model defines rights memory for text, images, prompts, generated media, guides, and content assets.

## 2. Required Fields

| Field | Requirement |
| --- | --- |
| Rights ID | Stable rights identifier. |
| Content ID | Related content identifier. |
| Content Name | Human-readable name. |
| Source Type | Original, generated, third-party, legacy candidate, or unknown. |
| Author / Creator | Creator or generation process. |
| License Type | License category. |
| Usage Rights | Usage boundary. |
| Modification Rights | Modification boundary. |
| Commercial Rights | Commercial boundary. |
| Attribution Required | Attribution state. |
| Evidence | Evidence reference. |
| Lineage Status | Lineage status. |
| Validation Status | Validation status. |

## 3. Boundary

This model prepares future rights review. It does not approve legality.
