# Asset Ownership Card Model V1

Status: ACTIVE_MEMORY_MODEL
Domain: Constitutional Memory Domain
Memory area: ownership-memory

## 1. Purpose

Asset Ownership Card Model defines how future asset ownership records are preserved.

## 2. Required Fields

| Field | Requirement |
| --- | --- |
| Ownership ID | Stable ownership identifier. |
| Asset ID | Related asset identifier. |
| Asset Name | Asset name. |
| Asset Class | Asset class. |
| Owner | Owner or claimant. |
| Author / Creator | Creator identity or generation process. |
| Source Type | Original, generated, third-party, legacy candidate, or unknown. |
| Creation Prompt | Prompt reference, if generated. |
| License Type | License category. |
| Usage Rights | Usage boundary. |
| Modification Rights | Modification boundary. |
| Commercial Rights | Commercial boundary. |
| Attribution Required | Yes, no, unknown, or conditional. |
| Evidence | Evidence reference. |
| Lineage Status | Lineage status. |
| Validation Status | Validation status. |

## 3. Boundary

Ownership cards preserve rights memory. They do not replace legal approval.
