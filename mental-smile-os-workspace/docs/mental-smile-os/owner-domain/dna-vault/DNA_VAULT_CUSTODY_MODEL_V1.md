# DNA Vault Custody Model V1

Status: ACTIVE_CONSTITUTION
Custodian: DNA Vault

## 1. Custody Principle

Custody means constitutional authority over source meaning. It does not mean archival storage, document ownership, runtime implementation, or operational execution.

## 3. Custody States

| State | Meaning |
| --- | --- |
| REQUIRED | DNA Vault must hold the structure as a constitutional custody category. |
| EMPTY_PENDING_EXTRACTION | No validated source asset has been accepted yet. |
| SOURCE_CANDIDATE | A Mental Smile Core source asset is being examined. |
| VALIDATED_SOURCE | Source asset has constitutional relevance but is not yet active construction. |
| ACTIVE_DOCTRINE | Doctrine is approved as active DNA Vault authority. |
| REJECTED_SOURCE | Source asset conflicts with Mental Smile OS foundation rules. |
| SUPERSEDED | Doctrine has been replaced by a newer validated doctrine. |

## 4. Custody Rules

- Each custody structure must remain inside DNA Vault.
- No custody structure creates a domain by itself.
- No custody structure authorizes implementation without a sequencing result.
- Source material must be classified before it is used.
- Legacy material defaults to SOURCE_CANDIDATE or REJECTED_SOURCE, never active authority.

## 5. Custody Boundary

DNA Vault may hold doctrines about archives, tools, legal, technical, monitoring, or operations, but it may not create those domains until sequencing approves them as the next required domain.
