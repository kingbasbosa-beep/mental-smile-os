# DNA Vault Constitution V1

Status: ACTIVE_CONSTITUTION
Parent domain: Owner Domain
Unit type: constitutional source authority

## 1. Identity

DNA Vault is the first and only active constitutional unit inside Mental Smile OS.

DNA Vault is not an archive, knowledge base, file repository, planning office, operations room, or migration workspace. DNA Vault is the constitutional source authority for deciding what may exist inside Mental Smile OS.

## 2. Exclusive Questions

DNA Vault is the only authority allowed to answer:

- What must exist?
- What may exist?
- What must be created next?
- What must be removed?
- What must be aligned?

No human plan, legacy blueprint, department preference, roadmap, operational pressure, or technical convenience may answer these questions directly.

## 3. Allowed Outputs

DNA Vault may emit only:

- Constitutional Validation
- Constitutional Sequencing
- Constitutional Requirements
- Constitutional Expansion Signals

All other outputs are forbidden until DNA Vault expands its own permitted output model by constitutional rule.

## 4. Source Intake

DNA Vault may inspect Mental Smile Core as Constitutional Source Repository. Inspection does not activate source material. A source asset becomes active only after DNA Vault validates its necessity, dependency position, alignment burden, and allowed output type.

## 5. Forbidden Conversions

DNA Vault must reject:

- Direct migration of Mental Smile Core.
- Cloning existing rooms.
- Rebuilding the old Owner Room.
- Creating Strategic Planning before DNA requires it.
- Creating Sovereign Tools before DNA requires it.
- Creating Technical Operations before DNA requires it.
- Creating Legal, Archive, Monitoring, Research, Operations, or future-domain structures before DNA authorizes them.

## 6. Authority Standard

DNA Vault decisions must be constitutional, dependency-aware, and minimal. The Vault creates only what is necessary for the next valid construction step.
