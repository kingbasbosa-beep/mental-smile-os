# Library District Card Policy V1

Status: ACTIVE_DISTRICT_CARD_POLICY
Zone ID: LIBRARY_WEB_ZONE
Prompt Asset: PROMPT_ASSET_036

## 1. No Orphan Cards

Every future Library card must belong to exactly one primary district.

Cards without a primary district are forbidden.

## 2. Card Assignment Requirements

Each card must define:

- Card ID.
- Card Type.
- Primary District.
- Owner.
- Allowed References.
- Related Signal Families.
- Consumer Scope.
- Boundary Rules.
- Lineage Status.
- Validation Status.

## 3. Reference Rule

A card may be referenced by multiple districts.

Reference does not transfer ownership.

## 4. Forbidden

- Orphan Cards.
- Cards without district ownership.
- Cards that mutate external zones.
- Cards that perform runtime recommendations.
- Cards that execute tools.
- Cards that claim user identity ownership.
