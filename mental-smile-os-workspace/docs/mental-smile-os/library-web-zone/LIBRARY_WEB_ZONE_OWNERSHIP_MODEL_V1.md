# Library Web Zone Ownership Model V1

Status: ACTIVE_OWNERSHIP_MODEL
Zone ID: LIBRARY_WEB_ZONE
Prompt Asset: PROMPT_ASSET_035

## Ownership

| Asset Class | Owner | Boundary |
| --- | --- | --- |
| Content Cards | Library Web Zone | App Zone may receive signals but does not own content. |
| Tool Cards | Library Web Zone | Tool discovery may be signaled; ownership remains Library. |
| Research Cards | Library Web Zone | Research materials remain Library-owned. |
| Resource Cards | Library Web Zone | Resource ownership remains Library. |
| District Registries | Library Web Zone | Other zones may not mutate district registries. |
| Internal Signals | Library Web Zone | External packages go through gateway only. |

## Non-Ownership

Library Zone does not own:

- Users.
- Rooms.
- Registrations.
- Profiles.
- Runtime Identity.
