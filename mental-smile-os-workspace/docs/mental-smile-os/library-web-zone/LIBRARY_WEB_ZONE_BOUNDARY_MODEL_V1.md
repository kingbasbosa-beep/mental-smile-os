# Library Web Zone Boundary Model V1

Status: ACTIVE_BOUNDARY_MODEL
Zone ID: LIBRARY_WEB_ZONE
Prompt Asset: PROMPT_ASSET_035

## Library Zone Does Not

- Own Users.
- Own Rooms.
- Own Registrations.
- Own Profiles.
- Own Runtime Identity.
- Mutate App Room Zone.
- Send direct signals to App surfaces.

## Library Zone Does

- Own Library content doctrine.
- Own Library tool card doctrine.
- Own Library research card doctrine.
- Own Library resource card doctrine.
- Own Library district registry.
- Communicate externally through LIBRARY_WEB_ZONE_GATEWAY only.

## Federation Boundary

Signals may travel through gateways and pipes.

Ownership may not travel with signals.
