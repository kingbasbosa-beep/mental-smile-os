# Library Resource Card Doctrine V1

Status: ACTIVE_RESOURCE_CARD_DOCTRINE
Zone ID: LIBRARY_WEB_ZONE
Prompt Asset: PROMPT_ASSET_035

## Purpose

Define Library resource cards as guides, resources, references, accessibility materials, recovery materials, family materials, and learning assets.

## Resource Card Rule

Resource cards belong to Library Web Zone.

They may be discovered by signals, but ownership does not transfer to App Zone or public profile zones.
