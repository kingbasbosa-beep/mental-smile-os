# Library District Signal Routing V1

Status: ACTIVE_SIGNAL_ROUTING_MODEL
Zone ID: LIBRARY_WEB_ZONE
Gateway ID: LIBRARY_WEB_ZONE_GATEWAY
Prompt Asset: PROMPT_ASSET_037

## Routing Model

All districts communicate externally only through:

LIBRARY_WEB_ZONE_GATEWAY.

Examples:

KNOWLEDGE_DISTRICT -> LIBRARY_WEB_ZONE_GATEWAY.

TOOLS_DISTRICT -> LIBRARY_WEB_ZONE_GATEWAY.

RESEARCH_DISTRICT -> LIBRARY_WEB_ZONE_GATEWAY.

## Forbidden Routing

KNOWLEDGE_DISTRICT X APP_ROOM_ZONE_GATEWAY.

TOOLS_DISTRICT X CLIENT_ROOM.

RESEARCH_DISTRICT X PROVIDER_ROOM.

VR_DISTRICT X CENTER_ROOM.

All routing must pass through LIBRARY_WEB_ZONE_GATEWAY.
