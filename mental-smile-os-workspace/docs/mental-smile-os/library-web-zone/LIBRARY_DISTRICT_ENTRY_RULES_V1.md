# Library District Entry Rules V1

Status: ACTIVE_GATEWAY_ENTRY_RULES
Zone ID: LIBRARY_WEB_ZONE
Gateway ID: LIBRARY_WEB_ZONE_GATEWAY
Prompt Asset: PROMPT_ASSET_037

## Gateway Accepts

LIBRARY_WEB_ZONE_GATEWAY accepts:

- Registered District.
- Registered Signal Family.
- Registered Card Source.
- Registered Resource Source.
- Valid Signal Package.

## Registered Districts

- KNOWLEDGE_DISTRICT.
- TOOLS_DISTRICT.
- RESEARCH_DISTRICT.
- ASSESSMENT_DISTRICT.
- VR_DISTRICT.
- RECOVERY_DISTRICT.
- FAMILY_DISTRICT.
- ACCESSIBILITY_DISTRICT.
- RESOURCE_DISTRICT.

## Rejection Conditions

- Unregistered district.
- Unregistered signal family.
- Orphan card source.
- Unknown resource source.
- Direct-to-external-zone routing attempt.
- Runtime execution request.
