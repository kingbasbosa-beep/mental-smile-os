# Library Tool Card Doctrine V1

Status: ACTIVE_TOOL_CARD_DOCTRINE
Zone ID: LIBRARY_WEB_ZONE
Prompt Asset: PROMPT_ASSET_035

## Purpose

Define Library tool cards as Library-owned assets used for tool discovery.

## Tool Card Rule

Tool cards may declare compatibility tags for discovery.

Tool cards do not execute tools in this step.

Tool discovery signals may travel through gateways.

Ownership remains Library Web Zone.
