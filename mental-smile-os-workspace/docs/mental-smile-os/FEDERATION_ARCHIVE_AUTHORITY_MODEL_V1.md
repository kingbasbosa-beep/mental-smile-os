# Federation Archive Authority Model V1

Status: ACTIVE_ARCHIVE_AUTHORITY_MODEL
Prompt Asset: PROMPT_ASSET_033

## Archive May

- Receive.
- Store.
- Index.
- Snapshot.
- Restore.

## Archive May Not

- Govern.
- Authorize.
- Mutate Runtime.
- Override zone sovereignty.
- Replace Owner approval.

## Archive Authority Rule

Archive preserves federation memory and recovery evidence. It does not command the federation.
