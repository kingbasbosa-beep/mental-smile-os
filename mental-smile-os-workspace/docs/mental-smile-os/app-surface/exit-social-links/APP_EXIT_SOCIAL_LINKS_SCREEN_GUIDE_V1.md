# App Exit Social Links Screen Guide V1

Status: READY
Screen ID: APP_EXIT_SOCIAL_LINKS_SCREEN
Surface: App Surface
Prompt Asset: PROMPT_ASSET_047

## Purpose

APP_EXIT_SOCIAL_LINKS_SCREEN is a calm public presence screen shown after room exit.

It gives users a safe way to leave a room and optionally find official Mental Smile public links.

## Allowed Public Links

- Website.
- Email.
- WhatsApp.
- Facebook.
- Instagram.
- LinkedIn.
- TikTok.
- Telegram.
- X.
- Zoom.
- GitHub.
- Domain / Web presence.

## Rules

- Public official links only.
- No sensitive user data.
- No private account data.
- No admin tools.
- No internal docs.
- No Firebase links.
- No credentials.

## Boundary

Documentation only.

No runtime, link implementation, Firebase, UI implementation, or external integration is created.
