## 1. Purpose

Splash introduces the Mental Smile OS App Surface with calm identity, Arabic-first welcome, and a clean entry moment.

It is not a login screen, booking screen, provider discovery screen, clinical screen, or legacy portal bridge.

## 2. Required Content

- Mental Smile logo / brand mark placeholder.
- Arabic welcome line.
- Short non-clinical support phrase.
- Continue button.
- Optional language toggle placeholder.
- Loading / status text placeholder.

## 3. Approved Arabic-First Copy

| Key | Arabic | English |
| --- | --- | --- |
| welcome | أهلا بك في Mental Smile | Welcome to Mental Smile |
| support_phrase | مساحة هادئة للدعم والاكتشاف | A calm space for support and discovery |
| continue | متابعة | Continue |
| arabic | العربية | Arabic |
| english | English | English |
| loading | جاري التحضير | Loading |

## 4. Forbidden Language

- Diagnosis language.
- Treatment promises.
- Booking language.
- Provider links.
- Clinical claims.
- Emergency claims.
- Old splash button labels copied directly.

## 5. Visual Direction

The visual should be minimal, warm, and calm:

- Soft warm background.
- Clear brand mark placeholder.
- One primary entry button.
- Small language toggle placeholder.
- No crowded UI.
- No medical or clinical imagery.

## 6. Runtime Boundary

This guide supports a static preview only.

It does not create Flutter implementation, Firebase routing, login routing, registration routing, or Home / Menu.
