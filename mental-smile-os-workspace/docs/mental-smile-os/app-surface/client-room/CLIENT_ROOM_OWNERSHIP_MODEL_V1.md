# Client Room Ownership Model V1

Status: ACTIVE_OWNERSHIP_MODEL
Screen: CLIENT_ROOM_SCREEN
Prompt Asset: PROMPT_ASSET_024

## 1. Purpose

Define ownership boundaries for Client Room components.

## 2. Ownership Records

| Component ID | Ownership | Notes |
| --- | --- | --- |
| CLIENT_ROOM_BACKGROUND | Mental Smile OS owns room background package. | Client owns personal use context, not the asset. |
| CLIENT_TOOL_BOARD | Mental Smile OS owns board package; client owns tool choices. | Tool choices are preferences, not recommendations. |
| CLIENT_TV_PANEL | Mental Smile OS owns panel package. | Content ownership remains with content packages. |
| CLIENT_PICTURE_FRAME | Mental Smile OS owns frame package; client owns uploaded personal image. | Upload requires future privacy/storage review. |
| CLIENT_NOTE_WIDGET | Mental Smile OS owns widget; client owns optional personal message. | Preset messages are OS language assets. |
| CLIENT_EXIT_CUP | Mental Smile OS owns exit control package. | Exit action only. |
| CLIENT_LEFT_SWITCHER | Mental Smile OS owns switcher control package. | Cycle only. |
| CLIENT_RIGHT_SWITCHER | Mental Smile OS owns switcher control package. | Cycle only. |

## 3. Rule

Ownership model does not create runtime permissions, legal approval, Firebase rules, or storage paths.
