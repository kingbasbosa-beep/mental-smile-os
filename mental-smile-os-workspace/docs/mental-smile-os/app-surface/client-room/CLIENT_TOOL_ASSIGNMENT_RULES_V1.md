# Client Tool Assignment Rules V1

Status: ACTIVE_ASSIGNMENT_RULES
Screen: APP_CLIENT_ROOM_SCREEN
Component: CLIENT_TOOL_BOARD
Prompt Asset: PROMPT_ASSET_026

## 1. Purpose

These rules define how selected tools relate constitutionally to the five fixed Tool Board slots.

## 2. Assignment Rules

- User selects a tool.
- Tool occupies one slot.
- One tool may occupy one slot at a time.
- Maximum five active tools may appear in the Client Room.
- A selected tool may be replaced.
- A selected tool may be removed.
- Empty slots remain valid.
- Slot ownership remains fixed to Client Room.
- Tool ownership remains separate from slot ownership.

## 3. Forbidden

- No tool execution.
- No recommendation engine.
- No ranking system.
- No scoring.
- No profile system.
- No interests system.
- No avatar system.
- No Firebase persistence.
- No runtime mutation.

## 4. Constitutional Boundary

Tool assignment defines placement only.

It does not define how a user selects tools in runtime, where selections are stored, how tools are executed, or how content is ranked.
