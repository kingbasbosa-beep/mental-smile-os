## What It Does

Client Room gives the client a calm personal space after registration.

It lets the client express tool preferences, see notifications/recommendations, display a personal picture, read or set motivation text, exit the room, and cycle room cards.

## How It Communicates

Conceptually through:

- Tool Selection Signals.
- Notification Signals.
- Picture Update Signals.
- Motivation Update Signals.
- Room Exit Signals.

## What It Does Not Do

- It is not a dashboard.
- It does not diagnose.
- It does not make clinical claims.
- It does not promise treatment.
- It does not match tools.
- It does not build runtime.
- It does not import old code.
