# Client Room Usage Rules V1

Status: ACTIVE_USAGE_RULES
Screen: CLIENT_ROOM_SCREEN
Prompt Asset: PROMPT_ASSET_024

## Allowed

- Personal room display.
- Tool preference selection.
- Notification and recommendation display.
- Sponsored content display when governed later.
- Educational highlights.
- Personal picture decoration after future approval.
- Preset motivation messages.
- Optional personal motivation message after future approval.
- Exit room action.
- Cycle room/tool cards.

## Forbidden

- Dashboard behavior.
- Admin functions.
- Operational complexity.
- Diagnosis.
- Clinical claims.
- Treatment promises.
- Tool matching.
- Recommendation storage inside Tool Board.
- Identity verification through picture frame.
- Logout/delete/emergency behavior through Exit Cup.
- Hidden legacy widgets.
- Firebase implementation.
- Runtime implementation.
