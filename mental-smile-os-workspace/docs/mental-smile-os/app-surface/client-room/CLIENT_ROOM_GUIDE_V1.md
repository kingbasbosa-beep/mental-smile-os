Status: ACTIVE_ROOM_DEFINITION

## 1. Principle

Client Room is not a dashboard.

Client Room is a personal space.

The room belongs to the client.

The room contains only meaningful objects.

No clutter.

No admin functions.

No operational complexity.

## 2. Approved Components Only

- CLIENT_ROOM_BACKGROUND.
- CLIENT_TOOL_BOARD.
- CLIENT_TV_PANEL.
- CLIENT_PICTURE_FRAME.
- CLIENT_NOTE_WIDGET.
- CLIENT_EXIT_CUP.
- CLIENT_LEFT_SWITCHER.
- CLIENT_RIGHT_SWITCHER.

Nothing else is approved in this definition.

## 3. Post Registration Doctrine

Client Registration creates identity only.

Client Room handles:

- Tool Board Selection.
- Picture Upload.
- Motivation Note.
- Recommendations display.
- Signals.
- Preferences.

## 4. Boundary

This guide attaches no assets, imports no images, creates no runtime, creates no Flutter, modifies no Firebase, and implements nothing.
