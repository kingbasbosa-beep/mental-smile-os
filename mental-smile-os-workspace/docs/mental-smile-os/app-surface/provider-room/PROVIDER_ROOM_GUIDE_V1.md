## 1. Purpose

Provider Room is an OS-native professional workspace for clinicians and specialists.

It follows the shared room doctrine: personal space, tool board, notification screen, private workspace, exit action, room ownership, tool-driven discovery, and no dashboard mentality.

## 2. Room Style

- Quiet.
- Professional.
- Psychology-inspired.
- Research-oriented.

## 3. Boundary

No old Provider Room UI is imported.

No runtime, Flutter, Firebase, tool registry, tool logic, recommendation engine, AI implementation, or Library migration is created.
