## Prompt Purpose

Recreate a calm Arabic-first Mental Smile login screen concept.

## Recreation Prompt

Create a minimal premium mental wellbeing app login screen for Mental Smile OS. Use a calm warm visual identity, Arabic-first labels, a simple email or phone field, password field, login button, language toggle, create account link, and forgot password link. Keep the screen clean, non-clinical, non-diagnostic, and free from crowded dashboard elements. Avoid medical imagery, booking language, provider ads, admin links, Firebase references, and credential exposure.

## Usage Rule

This prompt may recreate visual direction only.

It does not implement authentication.
