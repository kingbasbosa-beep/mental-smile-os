# Mental Smile OS Generation 1

Arabic-first mental health discovery, support, and ecosystem operating foundation.

Mental Smile OS Generation 1 is a governed release candidate. It defines how the ecosystem separates app rooms, library knowledge, public provider and center surfaces, owner governance, archive records, and signal movement.

## Key Pillars

- Arabic-first support and discovery
- Clear separation between zones
- Gateway-based signal movement
- Owner-governed constitutional change
- Admin Zero authority model
- Public-safe documentation
- Release candidate readiness

## Safety Statement

Mental Smile OS is not a clinic.

It is not a therapy provider.

It is not a diagnosis system.

It is not an emergency service.

It is not a platform for booking, payments, or session control.

## Release Candidate Statement

Generation 1 is a governed operating foundation and release candidate. It is ready for review and staged activation decisions, not automatic production deployment.
