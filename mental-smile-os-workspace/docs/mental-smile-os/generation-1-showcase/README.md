# Welcome To Mental Smile OS Generation 1

Mental Smile OS is an Arabic-first mental health discovery and support ecosystem foundation.

Generation 1 is the first governed release candidate. It explains how the project is structured, how its zones relate to each other, how signals move safely, and how public, app, library, commercial, and governance areas stay separated.

## Why The Project Exists

Mental health support ecosystems can become confusing when content, tools, registration, public profiles, internal governance, and operational records all collapse into one mixed system.

Mental Smile OS takes another route. It separates responsibilities, documents boundaries, and treats discovery, support, public visibility, and governance as connected but distinct parts of one ecosystem.

## What Generation 1 Achieved

Generation 1 created a governed foundation for:

- App surfaces and rooms
- Library and knowledge surfaces
- Provider and center public/registration separation
- Owner governance
- Monitoring and archive thinking
- Signal federation
- Constitutional records
- Release candidate readiness

It is a foundation, not a finished public service.
