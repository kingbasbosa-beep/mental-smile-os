# Forbidden Firebase Components V1

Status: FORBIDDEN_COMPONENTS_REGISTERED
Prompt Asset: PROMPT_ASSET_053

## Purpose

List Firebase components forbidden in Generation 1.

## Forbidden Components

- Legacy collections.
- Legacy roles.
- Legacy permissions.
- Legacy booking collections.
- Legacy payment collections.
- Legacy session collections.
- Legacy admin authority.
- Admin claim.
- Super admin claim.
- God mode claim.
- Hidden owner collections.
- Wildcard authority.
- Direct cross-zone mutation paths.
- Undefined collections.
- Temporary collections without expiry.
- Public access to private registration documents.
- Source-zone direct writes to archive snapshots.

## Rule

Anything not defined in Generation 1 Firebase implementation architecture is forbidden by default.
