Firebase implementation may include only approved Generation 1 collection families, signal families, storage boundaries, and custom claims declared in this package.

## Forbidden Principle

No Firebase implementation may introduce:

- Legacy admin authority.
- Admin claim.
- Super admin claim.
- God mode.
- Hidden owner collections.
- Booking collections.
- Payment collections.
- Session collections.
- Unknown collections.
- Direct cross-zone mutation.
