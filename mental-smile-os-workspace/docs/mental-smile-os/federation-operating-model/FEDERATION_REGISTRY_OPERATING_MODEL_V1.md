# FEDERATION_REGISTRY_OPERATING_MODEL_V1

## Purpose

Define how registries operate as traceability systems.

## Registry Network

Generation 1 registries track:

- Prompt assets.
- Cards.
- Signals.
- Routes.
- Zones.
- Gateways.
- Screens.
- Assets.
- Ownership.
- Archive states.
- Runtime targets.
- Execution waves.

## Registry Rule

No constitutional object is valid without a registry entry.

## Runtime Rule

Runtime reads registry truth. Runtime does not silently create registry truth.
