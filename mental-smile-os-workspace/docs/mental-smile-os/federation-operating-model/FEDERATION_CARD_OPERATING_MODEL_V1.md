# FEDERATION_CARD_OPERATING_MODEL_V1

## Purpose

Define how cards operate inside the federation.

## Card Doctrine

Cards describe. Runtime executes.

Cards are governance entities. Runtime consumes them.

## Card Operating Lifecycle

1. Birth Prompt.
2. Birth Authority.
3. Birth Lineage.
4. Registry Entry.
5. Validation.
6. Distribution.
7. Runtime Consumption.
8. Replacement or Freeze.
9. Archive.
10. Clone or Recreation.

## Forbidden

- No orphan cards.
- No unregistered runtime consumption.
- No card without birth prompt.
- No card without owner.
- No runtime object pretending to be a card without registration.
