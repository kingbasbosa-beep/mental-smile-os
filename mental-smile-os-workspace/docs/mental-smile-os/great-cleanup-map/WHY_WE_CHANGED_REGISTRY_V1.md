## Core Principle

We changed whenever an old structure:

- confused the public identity,
- created authority risk,
- made runtime dependent on source history,
- promised more than implementation delivered,
- mixed zones that needed sovereignty,
- or blocked honest release governance.

We preserved history whenever an old structure:

- explained why a decision changed,
- provided migration evidence,
- contained reusable lessons,
- or protected against repeating a mistake.
