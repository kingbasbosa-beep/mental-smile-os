# Runtime Shell Constitution V1

Status: ACTIVE_RUNTIME_CONSTITUTION
System: Mental Smile OS
Runtime shell: MENTAL_SMILE_OS_RUNTIME_SHELL

## 1. Purpose

Mental Smile OS Runtime Shell transforms the separated OS workspace from documentation-only into an independently navigable operating system shell.

## 2. Runtime Routes

| Route | Purpose |
| --- | --- |
| `/os` | OS Home and system state. |
| `/os/owner` | Owner Domain visibility. |
| `/os/owner/dna-vault` | DNA Vault visibility. |
| `/os/memory` | Constitutional Memory Domain visibility. |
| `/os/strategic-planning` | Strategic Planning Room visibility. |
| `/os/construction-studio` | Sovereign Construction Studio visibility. |

## 3. Runtime Boundaries

The runtime shell may:

- Display static placeholders.
- Display documentation-driven state.
- Provide independent navigation.
- Show visibility for existing OS rooms and domains.

The runtime shell may not:

- Build Residential Domain.
- Migrate old runtime.
- Attach to public marketplace home.
- Use Firebase.
- Add backend logic.
- Add forms or mutations.
- Create Technical Operations.
- Create Legal Department.

## 4. Data Source

Current data source:

```text
Static placeholders and documentation-driven display.
```

No Firebase dependency exists.
