# App Surface Build Order V1

Status: ACTIVE_BUILD_ORDER
Surface: APP SURFACE

## 1. Purpose

This document defines the clean App Surface screen construction order before any screen is built.

It does not build Splash, Menu, Client Room, Center Room, or Provider Room.

## 2. Build Order

1. Splash.
2. Home / Menu.
3. Client Registration.
4. Client Room.
5. Center Room.
6. Provider Room.

## 3. First Screen Rule

Splash must be rebuilt cleanly from:

- Purified assets.
- Approved localization terms.
- Constitutional welcome language.

No old splash layer may be copied directly.

## 4. Menu Warning

Home / Menu must be rebuilt cleanly.

Old menu is highly contaminated and may be used only as source evidence.

## 5. Client Room Warning

Client Room must be rebuilt cleanly using only:

- TV display.
- Tool board.
- Computer personal image.
- Exit cup.
- Left card navigation plaque.
- Right card navigation plaque.

No extra buttons.

No legacy overlays.

No old tab layers.
