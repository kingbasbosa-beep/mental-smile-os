# YAML Migration Sequence V1

Status: YAML_MIGRATION_SEQUENCE_DEFINED
Prompt Asset: PROMPT_ASSET_054

## Phase 1: Asset Inventory

Identify active, source, legacy, unknown, and future candidate assets.

## Phase 2: Asset Card Matching

Match every active candidate to an asset card.

## Phase 3: Ownership Verification

Verify ownership card, source type, rights, and zone ownership.

## Phase 4: Recreation Prompt Verification

Verify every asset can be recreated or regenerated through a registered recreation prompt.

## Phase 5: YAML Entry Drafting

Draft future YAML entries only after asset, ownership, and recreation prompt verification.

## Phase 6: Dead Entry Removal Plan

Plan removal of dead entries without modifying YAML in this step.

## Phase 7: Pre-runtime Validation

Validate that no unregistered asset, localization key, font, theme, or config reference enters the future runtime.

## Boundary

This sequence does not modify YAML.
