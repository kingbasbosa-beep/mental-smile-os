# YAML Asset Authority Matrix V1

Status: ASSET_AUTHORITY_MATRIX_CREATED
Prompt Asset: PROMPT_ASSET_054

## Purpose

Define who may register, own, reference, archive, and never activate YAML asset entries.

## Authority Matrix

| Asset Family | Owner | May Register | May Reference | Archive Owner | May Never Activate |
| --- | --- | --- | --- | --- | --- |
| App screen assets | APP_ROOM_ZONE | App Surface package owner | App runtime | SMART_ARCHIVE_ZONE | Legacy source path without OS rename |
| Library district assets | LIBRARY_WEB_ZONE | Library district owner | Library runtime, approved consumers | SMART_ARCHIVE_ZONE | App direct ownership |
| Provider registration assets | PROVIDER_REGISTRATION_WEB_ZONE | Provider registration zone | Registration runtime | SMART_ARCHIVE_ZONE | Provider public zone direct private path |
| Provider public assets | PROVIDER_PUBLIC_WEB_ZONE | Provider public zone | Public profile runtime | SMART_ARCHIVE_ZONE | Private document paths |
| Center registration assets | CENTER_REGISTRATION_WEB_ZONE | Center registration zone | Registration runtime | SMART_ARCHIVE_ZONE | Center public zone direct private path |
| Center public assets | CENTER_PUBLIC_WEB_ZONE | Center public zone | Public profile runtime | SMART_ARCHIVE_ZONE | Private contract paths |
| Governance assets | Governance zones | Owning governance zone | Governance runtime | SMART_ARCHIVE_ZONE | Hidden admin assets |
| Showcase assets | Mental Smile OS | Showcase package owner | Public documentation | SMART_ARCHIVE_ZONE | Internal secret docs |

## Rule

YAML reference does not transfer ownership.
