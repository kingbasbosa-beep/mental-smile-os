## Forbidden YAML Entries

- Old asset paths.
- Deprecated placeholders.
- Duplicate old/new assets.
- Unused asset folders.
- Temporary assets without expiry.
- Legacy splash assets not renamed.
- Legacy home assets not renamed.
- Legacy client room assets not registered.
- Booking icons.
- Payment proof assets.
- Session assets.
- Admin legacy assets.
- Unknown localization files.
- Unknown font entries.
- Dead theme entries.
- Duplicate theme assets.
- Old theme placeholders.

## Default Rule

Anything not registered in Generation 1 YAML implementation planning is forbidden by default.
