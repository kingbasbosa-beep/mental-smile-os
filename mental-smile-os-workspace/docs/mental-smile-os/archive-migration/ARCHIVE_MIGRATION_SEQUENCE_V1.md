Verify origin, evolution, replacement, successor, archive status, and retention status.

Prepare archive packages for verified items.

## Phase 4: Archive Migration

Move archive packages only after future explicit authorization.

Validate that active workspace, active snapshot, active clone package, active rebirth prompt, and active docs remain intact.
