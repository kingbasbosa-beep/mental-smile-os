# Archive Migration Plan V1

Status: ARCHIVE_PLAN_CREATED
Prompt Asset: PROMPT_ASSET_051
Parent Prompt: PROMPT_ASSET_050

## Purpose

Define the official Generation 1 historical preservation and archive migration doctrine.

This plan defines what remains active, what becomes archive, what becomes historical evidence, and what becomes museum material.

## Preservation Categories

| Category | Meaning |
| --- | --- |
| ACTIVE | Current operating source of truth. |
| ACTIVE_REFERENCE | Current required reference package. |
| ARCHIVE_CANDIDATE | Candidate for future archive packaging after verification. |
| HISTORICAL_EVIDENCE | Preserved as lineage or source proof. |
| MUSEUM_ARTIFACT | Preserved as significant history of Mental Smile evolution. |
| UNKNOWN | Not classified and not safe to move or delete. |

## Active Preservation Rule

Mental Smile OS Generation 1 remains active.

Mental Smile Core / clean2 remains source repository and historical evidence until future classification says otherwise.

## No Movement Rule

No file may be moved, archived, deleted, renamed, or migrated by this plan.

Classification only.
