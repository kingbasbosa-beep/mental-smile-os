# Public Profiles Web Surface Boundary V1

Status: FUTURE_WEB_BOUNDARY
Surface: PUBLIC PROFILES WEB SURFACE

## 1. Purpose

Public Profiles Web Surface provides external discovery and visibility for centers, providers, and public service pages.

## 2. Contains

- Centers public pages.
- Providers public pages.
- Public service discovery pages.

## 3. Logic Boundary

Public Profiles Web Surface may:

- Present public discovery information.
- Link users toward app entry points when approved.
- Display provider and center visibility records.

Public Profiles Web Surface may not:

- Host private Client Room.
- Host Owner OS.
- Host Smart Archive.
- Become Library Tool Catalog.
- Copy old public marketplace home as active runtime.

## 4. Connections

Allowed connections:

- Surface Link to App Surface registration entry.
- Surface Link to Library content when relevant.
- Signal Pipe for profile visibility status when future governance allows it.
