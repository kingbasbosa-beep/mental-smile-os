## Role

GitHub Pages is the Mental Smile OS technical documentation and showcase surface.

Canonical role:

`https://kingbasbosa-beep.github.io/mental-smile-os`

## What GitHub Pages Is

- OS story
- Generation 1 showcase
- architecture overview
- public technical credibility layer
- release-candidate explanation

## What GitHub Pages Is Not

- not the official production app landing
- not the Firebase runtime target
- not a login surface
- not a booking/payment/session surface
- not a replacement for Firebase Hosting

## Public Identity Rule

Firebase is the official product landing. GitHub Pages is the OS / technical documentation showcase. They should link to each other without duplicating ownership.
