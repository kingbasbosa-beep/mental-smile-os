## Required Before Firebase Implementation

- Confirm final runtime target root.
- Confirm collection family ownership.
- Confirm read/write scopes.
- Confirm gateway authority.
- Confirm archive scope.
- Confirm no wildcard authority.

## Boundary

This checklist does not implement Firebase, Firestore, Storage, backend rules, or security rules.
