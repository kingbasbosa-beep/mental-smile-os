# Mental Smile Firebase Landing Page

This folder contains the lightweight public landing page intended for Firebase Hosting.

## Files

- `index.html`
- `styles.css`
- `landing-links.js`
- `README.md`
- `LANDING_PAGE_REPORT_V1.md`

## Identity

The page presents the public brand:

```text
Mental Smile
```

Mental Smile OS appears only as a secondary technical foundation link.

## Language

Arabic is the default language:

```html
<html lang="ar" dir="rtl">
```

English is available through a local language toggle.

## Links

All public destination URLs are centralized in:

```text
landing-links.js
```

## Safety

The page does not include forms, tracking, cookies, analytics, clinical claims, diagnosis promises, treatment promises, emergency service promises, booking authority, payment authority, or session authority.

No Firebase configuration was changed.
