# Accessibility TV Card V1

Status: ACTIVE_GOVERNANCE_CARD
Classification: ACCESSIBILITY_TV_FOUNDATION
Phase: 7B
Runtime effect: none

## Purpose

Define the Accessibility TV doctrine before implementation.

Accessibility TV is a video-first learning and barrier-removal surface.

## YouTube-First Philosophy

Accessibility TV should prefer YouTube-first content where appropriate because video can reduce complexity for many users.

YouTube-first means:

- video can explain faster than dense text
- captions and visual pacing can support comprehension
- public videos can be shared and revisited
- users can learn without navigating complex documents first

## Video Over Complexity

When a topic can be explained simply through video, the gateway should favor video over complex written navigation.

This does not remove written alternatives. It means video may be the first access path.

## Content Rules

Accessibility TV content should be:

- clear
- calm
- non-diagnostic
- non-stigmatizing
- source-aware
- easy to leave
- easy to revisit

## Boundary

This card does not create a YouTube integration, video player, playlist, content collection, or runtime screen.
