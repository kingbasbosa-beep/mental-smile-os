# Residential Domain Build Strategy V1

Status: STRATEGY_READY_FOR_OWNER_REVIEW
Room: Strategic Planning Room
Target: future Residential Domain
Runtime effect: none

## 1. Goal

Prepare the strategy for building the future Residential Domain.

This document does not build Residential Domain.

## 2. Strategic Definition

Future Residential Domain should represent the client/residential experience after constitutional purification. It should gather client-facing identity, onboarding, dashboard, support pathways, discovery, accessibility, library/content, saved destinations, selected tools, profile/account, localization, assets, routes, and data boundaries into a clean build package.

## 3. Build Principles

- Do not copy Mental Smile Core as-is.
- Use `Extract -> Purify -> Reclassify -> Rebuild`.
- Treat existing code and documents as source candidates only.
- Separate residential client experience from monitoring, technical execution, legal approval, and operations.
- Preserve prompt, guide, card, signal, memory, and lineage language for every future asset.
