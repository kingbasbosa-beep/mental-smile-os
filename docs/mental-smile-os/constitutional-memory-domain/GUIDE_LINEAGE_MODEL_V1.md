# Guide Lineage Model V1

Status: ACTIVE_MEMORY_MODEL
Domain: Constitutional Memory Domain
Owning unit: Memory Lineage Unit

## 1. Purpose

Guide Lineage Model preserves evolutionary chains for constitutional guide assets.

Guide lineage is the parent-chain protection layer for future cards. If guide lineage breaks, all dependent card lineage must be reviewed.

## 2. Tracked Guide Events

| Event | Meaning |
| --- | --- |
| Guide Creation | A guide asset first entered constitutional memory. |
| Guide Expansion | A guide gained additional scope or supported asset relationships. |
| Guide Replacement | A guide was replaced by a new guide asset. |
| Guide Alignment | A guide was aligned to DNA Vault or memory requirements. |
| Guide Retirement | A guide was removed from active use but preserved as memory. |
| Guide Supersession | A guide was formally superseded by another guide. |

## 3. Lineage Chain Requirements

Every guide lineage chain must preserve:

- Guide ID.
- Event type.
- Event date.
- Birth prompt.
- Birth authority.
- Birth justification.
- Prior guide ID, if any.
- Replacement guide ID, if any.
- Related cards.
- Related signals.
- Related registries.
- Related descendants.
- Validation result.

## 4. Broken Guide Lineage Conditions

Guide lineage is broken when:

- Birth prompt is missing.
- Birth authority is unknown.
- Registry entry is missing.
- Validation status is missing.
- Replacement lacks prior guide reference.
- Supersession points to a missing guide ID.
- A dependent card references a guide with broken lineage.

## 5. Boundary

Guide Lineage Model traces guide evolution. It does not decide whether a new guide should exist beyond recording validation supplied by Memory Validation Unit or DNA Vault.
