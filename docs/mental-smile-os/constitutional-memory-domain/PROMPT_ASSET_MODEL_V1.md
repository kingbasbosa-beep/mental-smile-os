# Prompt Asset Model V1

Status: ACTIVE_MEMORY_MODEL
Domain: Constitutional Memory Domain
Owning registry: Prompt Memory Registry

## 1. Purpose

Prompt Asset Model defines how prompts are preserved as constitutional assets when they generate Mental Smile OS structures.

Prompts are constitutional memory assets. Generated domains, units, guides, registries, and signals are constitutional descendants of the prompt-authority event that produced them.

## 2. Required Fields

| Field | Requirement |
| --- | --- |
| Prompt ID | Stable identifier for the prompt asset. |
| Prompt Name | Human-readable name of the prompt. |
| Prompt Type | Constitutional class of prompt. |
| Prompt Version | Version of the prompt asset record. |
| Creation Date | Date the prompt generated constitutional output. |
| Generated Assets | Outputs created by the prompt. |
| Generated Domains | Domains created by the prompt. |
| Generated Guides | Guides or constitutional models created by the prompt. |
| Generated Registries | Registries created by the prompt. |
| Generated Signals | Signals emitted or recorded by the prompt output. |
| Parent Prompt | Prior prompt that authorized or required this prompt, if any. |
| Related Prompts | Other prompt assets connected by lineage. |
| Status | Current memory status. |
| Strategic Value | Constitutional value without granting planning authority. |
| Lineage Status | Completeness of prompt lineage. |

## 3. Prompt Types

| Prompt Type | Meaning |
| --- | --- |
| FOUNDATIONAL_PROMPT | Prompt that creates first-principles OS foundation or first required constitutional domain. |
| MEMORY_PROMPT | Prompt that creates or updates constitutional memory records. |
| EXTRACTION_PROMPT | Prompt that extracts source material for purification and placement. |
| VALIDATION_PROMPT | Prompt that validates memory or lineage completeness. |

## 4. Status Values

| Status | Meaning |
| --- | --- |
| REGISTERED | Prompt asset is tracked in memory. |
| LINEAGE_ESTABLISHED | Prompt has complete origin and descendant links. |
| VALIDATED | Prompt passed memory validation. |
| SUPERSEDED | Prompt has been replaced by another prompt asset. |
| INVALID | Prompt lineage or generated output is contradictory. |

## 5. Separation Rule

Prompt assets may explain how constitutional outputs were born. They may not authorize new outputs after the fact.
