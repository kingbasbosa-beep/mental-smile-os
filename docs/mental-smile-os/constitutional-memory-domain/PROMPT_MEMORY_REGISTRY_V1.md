## 1. Purpose

Prompt Memory Registry tracks prompts that generated constitutional structures inside Mental Smile OS.

It preserves prompt lineage only. It does not create domains, authorize expansion, govern source meaning, plan future construction, or replace DNA Vault authority.

## 2. Registry Boundary

Prompt Memory Registry is housed inside Memory Registry. It is not a new unit inside Constitutional Memory Domain.

Allowed actions:

- Preserve prompt assets.
- Link prompts to generated constitutional descendants.
- Trace prompt lineage.
- Validate prompt lineage completeness.

Forbidden actions:

- Create domains.
- Authorize expansion.
- Govern constitutional source authority.
- Convert Mental Smile Core artifacts into active OS structures.
- Create Alignment Domain, Strategic Planning, Tool Centers, Technical Operations, Legal Domain, or Archive Domain.
