## 4. PHASE 1 DISTRIBUTION ENGINE TEST PLAN

Distribution is not executed in Phase 1 creation freeze. This section prepares the future controlled test only under the Constitutional Card Purity Doctrine.

Purity rule for the future test:

| Rule | Requirement |
|---|---|
| Sole operational card | Only the latest valid constitutional card may exist in active guide scope. |
| Replacement is atomic | Replacement removes the prior operational card from active scope before the new card becomes active. |
| No operational retention | Prior card versions are not retained, frozen, deprecated, shadowed, or marked inactive inside active guide scope. |
| Archive is external | Archive processing is outside Phase 1 and is not defined here. |

### 4.1 Test Card Selection

| Field | Value |
|---|---|
| Selected Test Card | `card.registry.surface_department` |
| Reason | Safe metadata-only registry card. It is a Master Guide source card, has no runtime effect, and does not touch Firebase, routes, UI, or ARB. |
| Current Distribution Status | `MASTER_GUIDE_ONLY` |
| Current Status | `ACTIVE_CONSTITUTIONAL_CARD` |

### 4.2 Test Mutation

| Mutation ID | Mutation | Type | Runtime Impact |
|---|---|---|---|
| `mutation.phase1.surface_registry.owner_label` | Change Owner from `Department Steward` to `Department Steward / Compliance Observer` on a replacement candidate generated outside active scope. | Harmless metadata change | None |

### 4.3 Expected Behavior

| Expected Behavior | Required Result |
|---|---|
| Prior card removed from active scope | The prior operational instance of the selected governed object ceases to exist operationally before replacement activation. |
| Prior card cannot be unblocked | There is no operational prior card to unblock after replacement. |
| Replacement card generated | A replacement instance is generated as the sole active candidate. |
| Replacement becomes sole active card | Active Master Guide scope contains only the replacement instance for the governed object. |
| Both cards cannot coexist | The test fails if both versions appear in active guide scope. |
| No legacy copy remains | The test fails if legacy, frozen, deprecated, retained, compatibility, shadow, transitional, historical, or inactive copies appear in active guide scope. |
| Archive behavior not defined | Phase 1 produces no external preservation object, no storage behavior, no retention behavior, and no deletion behavior. |
| Completion report generated | Test report records selected card, mutation, replacement result, purity status, and active-card count. |

### 4.4 Backup Test Plan

Backup generation is not executed here and backup storage behavior is not defined in Phase 1. Future backup planning is external to active card purity enforcement.
