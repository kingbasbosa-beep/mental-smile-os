# TRANSITIONAL TERMS REGISTRY

## Rule

Transitional vocabulary is temporarily tolerated only where an existing active consumer still uses it. It must not define new system doctrine, new runtime ownership, or new localization keys. Each use requires an explicit constitutional destination.

## Migration Direction

- Request -> declaration, contact signal, support signal, or resource interest according to context.
- Review -> observation, readiness inspection, or policy interpretation without decision authority.
- Pending -> incomplete, draft, or awaiting self-completion.
- Inbox -> communication stream or signal stream.
- Dashboard -> room, observatory, registry, or personal space.
- Case -> support signal, safety event, or continuity record.
- Follow-up -> continuity resource or chosen support continuation.
- Status -> readiness, visibility, safety level, or lifecycle state only when mechanically derived.
