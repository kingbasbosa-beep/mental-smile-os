# LOCALIZATION MIGRATION WAVE 2

## Theme

Legacy language and transitional vocabulary.

## Mission

Move valid concepts away from request/review/pending/inbox/dashboard/status wording into registered language: declaration, signal, readiness, visibility, room, observatory, registry, support signal, contact, and resource. This is a future implementation wave only.

## Targets

- Dormant keys that may still represent valid concepts.
- Duplicate meaning groups.
- Transitional status and request wording.
- Hardcoded labels that are constitutionally valid but bypass localization governance.
- Registry ownership gaps for AUTH and SAFETY vocabulary.

## Constitutional Justification

The concept may survive, but not with ungoverned or transitional phrasing. Wave 2 turns valid meaning into governed language.
