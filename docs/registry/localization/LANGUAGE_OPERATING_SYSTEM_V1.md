# LANGUAGE OPERATING SYSTEM V1

## Constitutional Purpose

The Mental Smile Language Operating System governs how language is born,
expressed, validated, evolved, frozen, and inherited. It treats language as a
system of meaning and authority, not a collection of translations.

## System Components

| Layer | Source | Responsibility |
|---|---|---|
| Doctrine | Constitutional registries | Defines allowed system meaning |
| Vocabulary | Term cards | Owns terms, contexts, lifecycle, and replacements |
| Generation | `LANGUAGE_ENGINE_V1.md` | Produces governed copy |
| Arabic expression | `ARABIC_LANGUAGE_CONSTITUTION.md` | Governs natural Arabic |
| English expression | `ENGLISH_LANGUAGE_CONSTITUTION.md` | Governs natural English |
| Patterns | `LANGUAGE_PATTERN_LIBRARY.md` | Structures output by surface type |
| AI conduct | `AI_LANGUAGE_GENERATION_RULES.md` | Constrains AI generation and validation |
| Audit | Governance reports | Measures coverage, drift, and unresolved residue |

## How Language Is Born

Language begins with a declared human intent, not a draft phrase.

1. The intent and audience are declared.
2. The output type and destination are declared.
3. One registry is selected as the concept owner.
4. Active term cards supply the allowed meaning.
5. Doctrine validation removes forbidden authority.
6. A shared language-neutral meaning is formed.
7. Arabic and English are composed independently.
8. Parity and surface rules are validated.
9. The result is admitted only with traceable term IDs.

If no registry owns the concept, language is not born. Governance must decide
the concept first.

## How Language Evolves

Language evolution is versioned and explicit:

1. a gap, ambiguity, or drift is discovered;
2. the affected owner registry evaluates the meaning;
3. a new term card or card revision is proposed;
4. Arabic and English constitutional meanings are reviewed together;
5. lifecycle and replacement relationships are declared;
6. impacted consumers are inventoried;
7. the registry version advances;
8. migration occurs separately from governance.

Existing copy never establishes doctrine merely because it is widespread.

## How Language Is Governed

### Ownership

- Every doctrine-bearing term has one owner registry.
- Consumers use meaning; they do not redefine it.
- Shared concepts reference one canonical term card.

### Admission

A term enters ACTIVE only when it has:

- a stable definition;
- constitutional meaning;
- Arabic and English expressions;
- allowed and forbidden contexts;
- one owner;
- no unresolved duplicate;
- a justified current purpose.

### Deprecation

Deprecated terms retain historical traceability but cannot originate new copy.
They declare replacements and affected contexts.

### Prohibition

Forbidden terms and their underlying authority models are blocked. Renaming a
forbidden concept does not admit it.

### Observation

Monitoring may report drift, missing ownership, forbidden usage, and parity
failure. Monitoring cannot approve language outside registry rules.

## How AI Generates Language

AI acts as a constrained composer:

1. normalize intent;
2. resolve owner;
3. resolve approved vocabulary;
4. reject forbidden doctrine;
5. build shared meaning;
6. compose Arabic and English;
7. validate parity;
8. return governance evidence.

AI cannot legislate. It may identify a vocabulary gap, but only registry
governance may admit the missing concept.

## How Existing Language Is Validated

Existing language is decomposed into intent, authority, state, actor, action,
and consequence. It is then checked against current registry meaning.

The result is:

- `PASS` for constitutional language;
- `REVISE` for valid meaning with invalid expression;
- `BLOCK` for forbidden doctrine or missing ownership;
- `HISTORICAL_ONLY` for preserved evidence outside active language.

Validation applies equally to UI text, keys, hardcoded strings, notifications,
marketing, policies, signal names, cards, and generated AI language.

## Constitutional Freeze

A language release may be constitutionally frozen only when:

1. every active doctrine-bearing string maps to an owner registry;
2. every active concept maps to ACTIVE term cards;
3. no forbidden doctrine exists in active copy;
4. transitional exceptions are enumerated and time-bounded;
5. Arabic and English parity is complete;
6. missing and duplicate meanings are resolved;
7. generated language passes all engine gates;
8. no active hardcoded language bypasses governance;
9. registry and consumer versions are recorded;
10. audit evidence is reproducible.

Freeze means meanings cannot drift silently. It does not mean language can
never evolve.

## Freeze Enforcement Model

| Gate | Failure Result |
|---|---|
| Missing owner | Block |
| Unregistered doctrine term | Block |
| Forbidden lifecycle | Block |
| Transitional term without exception | Block |
| Context violation | Block |
| Arabic Constitution failure | Block |
| English Constitution failure | Block |
| Meaning parity failure | Block |
| Pattern failure | Revise |
| Historical evidence in active output | Block |

## Future Capsule Inheritance

A future capsule inherits language through a declared language manifest:

- capsule ID and version;
- purpose and audience;
- owning registry;
- allowed supporting registries;
- term card IDs and versions;
- allowed output types;
- prohibited doctrine;
- Arabic and English style profiles;
- transitional exceptions, if any;
- validation evidence.

A capsule may narrow vocabulary but cannot broaden authority. It may introduce a
new concept only after that concept is admitted to the central registry.

Capsules must not fork canonical meanings. If a local expression is necessary,
it remains an expression of the same registered term.

## Historical Language

Historical language may survive only in clearly marked historical documents or
audit evidence. It cannot be:

- used as a generation example;
- copied into active patterns;
- treated as a compatibility source;
- used to infer current doctrine.

## Current Governance Boundary

The first registry contains 120 governed terms across 12 registries. The
Operating System is designed, but constitutional freeze remains blocked by the
open findings recorded in `LANGUAGE_GOVERNANCE_REPORT.md`, including unclassified
keys, hardcoded candidates, old-doctrine findings, duplicate meanings, locale
parity, and missing dedicated AUTH and SAFETY vocabulary ownership.

## Final Principle

Language is born from governed meaning.

Registries own meaning.

Patterns shape expression.

Arabic and English carry equal authority.

AI composes but does not legislate.

Freeze prevents silent drift.
