# LOCALIZATION MIGRATION WAVE 1

## Theme

High-risk doctrine.

## Mission

Remove or replace language that contradicts the constitutional system before any cosmetic cleanup. This is a future implementation wave; this document does not modify anything.

## Targets

- Approval/rejection/acceptance language.
- Assignment, referred cases, ownership, inbox-as-work-queue language.
- Booking, session, payment, package request, and manual review language.
- Control-room or admin authority phrasing.
- Diagnostic or deficit-first phrasing where it defines people.
- Missing parity key `statusCenterFollowUp`.

## Constitutional Justification

The Language Engine blocks forbidden doctrine before copy quality. These findings can silently restore extinct authority even if the screen still compiles.
