# RESIDENTIAL LANGUAGE POLICY

## الهوية

- **Policy ID:** `RESIDENTIAL_LANGUAGE_POLICY`
- **النطاق:** الأسطح الداخلية، الشخصية، السكنية، والغرف الخاصة.
- **الحالة:** حوكمة لغوية فعالة.
- **الأولوية:** تطبق بعد تحديد معنى المصطلح ومالكه، وقبل توليد النص النهائي.

## الأسطح المشمولة

- Client Room
- Personal Space
- Provider Room داخل التطبيق
- Center Room داخل التطبيق
- أي غرفة داخلية أو شخصية
- الأدوات والكروت والإشعارات والتنقل الداخلي داخل هذه الأسطح

## المبدأ

السطح السكني ليس عيادة، ولا ملف حالة، ولا مساحة تشغيل علاجي. هو مساحة
إنسانية تساعد الشخص على التعبير والاستكشاف والتعلم والوصول إلى الأدوات
والموارد والإشارات التي يختارها.

## اللغة المسموحة

- لغة ترحيبية وداعمة ومحتوية.
- لغة دافعية تحافظ على الاختيار.
- لغة تعليمية واستكشافية.
- لغة الهوية المختارة والتطلعات ونقاط القوة.
- الأدوات والإشارات والموارد والأهداف والتفضيلات.
- الأمل والانتماء والنمو والتعلم.
- تفضيلات التواصل وإمكانية الوصول والخصوصية.
- الوجهات المحفوظة والمحتوى والمعرفة.

## اللغة الممنوعة

يمنع استخدام المصطلحات العلاجية أو الطبية كلغة صادرة عن المنصة في:

- العناوين؛
- الأزرار؛
- التابات؛
- أسماء الأقسام؛
- نصوص الإرشاد؛
- الإشعارات؛
- الحالات الفارغة؛
- رسائل النجاح والخطأ؛
- توصيف الشخص أو رحلته.

تشمل المصطلحات الممنوعة:

- علاج / Treatment
- جلسة / Session
- تشخيص / Diagnosis
- خطة علاج / Treatment Plan
- حالة / Case
- متابعة علاجية / Treatment Follow-up
- تقييم علاجي / Treatment Assessment
- تدخل علاجي / Treatment Intervention
- مريض / Patient
- امتثال علاجي / Treatment Compliance

## الحدود الدستورية

1. لا تقول المنصة إن الشخص يحتاج إلى علاج أو تشخيص.
2. لا تصف المنصة الشخص كحالة.
3. لا تدير المنصة خطة علاج أو علاقة علاجية.
4. لا تستخدم إشارات الشخص لاستنتاج تشخيص.
5. لا تتحول التوصية إلى توجيه علاجي.
6. لا يتحول Provider Room أو Center Room الداخلي إلى مساحة إدارة علاج.

## الإعلانات والكروت الممولة

يجوز أن يظهر محتوى يقدم معلومات عن خدمة علاجية داخل إعلان أو كارت ممول
بشروط:

- النص منسوب بوضوح إلى مقدم الخدمة أو المركز، وليس إلى Mental Smile.
- لا يقدم السطح السكني التفاصيل العلاجية الكاملة.
- لا يوجد زر حجز أو بدء علاج أو اختيار علاج.
- الإجراء الوحيد هو الانتقال إلى صفحة عامة تجارية منفصلة.
- لا تستخدم بيانات الغرفة الشخصية لإصدار حكم علاجي.

الصياغة المفضلة:

- `اعرض معلومات مقدم الخدمة`
- `استكشف الصفحة العامة`
- `اعرف المزيد عن الخدمة`

الصياغة الممنوعة:

- `احجز جلسة`
- `ابدأ علاجك`
- `اختر خطة العلاج`
- `المختص المناسب لحالتك`

## بدائل اللغة

| بدلًا من | استخدم |
|---|---|
| جلسة | تواصل، وقت خدمة، معلومات خدمة، حسب السياق |
| علاج | دعم، موارد، اتجاه نحو التعافي، معلومات عامة |
| تشخيص | إشارة معلنة، تفضيل، موضوع اهتمام |
| حالة | شخص، محادثة، إشارة دعم، بلاغ أمان |
| خطة علاج | أهداف، أدوات، مسار اختياري، تفضيلات |
| متابعة علاجية | دعم الاستمرارية، موارد الاستمرارية |
| تقييم علاجي | استكشاف، تأمل ذاتي، معلومات معلنة |
| تدخل علاجي | إرشاد أمان عند وجود خطر حقيقي |

## أمثلة

### ALLOWED

- `ما الذي يمنحك الأمل؟`
- `اختر الأدوات التي تناسب أهدافك.`
- `شارك الإشارات التي تختارها.`
- `استكشف موارد التعافي.`
- `حدد طريقة التواصل التي تفضلها.`

### FORBIDDEN

- `ابدأ جلستك العلاجية.`
- `تم تشخيص حالتك.`
- `خطة العلاج الخاصة بك.`
- `تم تعيين مختص لحالتك.`
- `تابع علاجك من هنا.`
