# ADMINISTRATIVE LANGUAGE POLICY

## الهوية

- **Policy ID:** `ADMINISTRATIVE_LANGUAGE_POLICY`
- **النطاق:** أسطح الرصد والحوكمة والتقارير والتحليلات الداخلية.
- **الحالة:** حوكمة لغوية فعالة.

## الأسطح المشمولة

- Monitoring Room
- Owner Room
- التقارير
- التحليلات
- الرصد
- الملاحظات الداخلية
- قراءات الأنماط والمخاطر
- مستندات الحوكمة النشطة

## المبدأ

الإدارة ترصد وتحلل وتحكم الحدود. لا تقدم علاجًا، ولا تدير علاقة علاجية،
ولا تملك رحلة العميل، ولا تعين مقدم خدمة، ولا تقبل أو ترفض شخصًا.

## اللغة المسموحة

- تقرير
- تحليل
- رصد
- إشارة
- نمط
- قراءة
- فئة
- مخاطر
- ملاحظة
- جاهزية
- ظهور
- اكتمال
- اتجاه
- دليل
- مصدر

## السماح المحدود للمصطلحات العلاجية والتشغيلية

يجوز استخدام المصطلحات العلاجية أو التشغيلية فقط عندما تكون:

- قيمة بيانات موجودة؛
- تصنيفًا داخل تقرير؛
- قراءة تحليلية؛
- اقتباسًا من إعلان مقدم خدمة؛
- سياقًا تاريخيًا؛
- عنصرًا في تدقيق الامتثال اللغوي؛
- معلومة ضرورية لفهم نمط أو خطر.

أمثلة مسموحة:

- `عدد الصفحات التجارية التي تستخدم مصطلح "جلسة".`
- `تحليل ظهور مصطلحات العلاج في الإعلانات.`
- `التقرير رصد إشارة أمان عالية الخطورة.`
- `المركز يعلن برنامج علاج ضمن صفحته العامة.`

## المواضع الممنوعة

حتى داخل الأسطح الإدارية، يمنع استخدام اللغة العلاجية أو التشغيلية في:

- أسماء التابات؛
- الأزرار؛
- أسماء الأقسام النشطة؛
- أوامر التنفيذ؛
- تسميات توحي بامتلاك رحلة الشخص؛
- أسماء قوائم العمل التي تعيد queue ownership.

أمثلة ممنوعة:

- `إدارة الحالات`
- `تعيين مختص`
- `قبول حالة`
- `رفض حالة`
- `التحكم في جلسة`
- `متابعة علاجية من المنصة`
- `طابور الحالات`
- `مالك الحالة`
- `غرفة التحكم`
- `عمليات العلاج`

## حدود Monitoring Room

Monitoring Room:

- يرصد الإشارات.
- يعرض الجاهزية والظهور والنضارة والمخاطر.
- يعرض تقارير وقراءات.
- لا يغير الجاهزية يدويًا.
- لا يعين الأشخاص.
- لا يوجه الحالات.
- لا يملك المتابعة.

## حدود Owner Room

Owner Room:

- يصدق على العقيدة والاستراتيجية.
- يقرر حدود النظام.
- يراجع صحة السجلات والسياسات.
- لا يتخذ قرارات علاجية لأشخاص.
- لا يدير يوميات مقدم الخدمة أو المركز.
- لا يصبح Admin Hub أو Control Room.

## بدائل اللغة

| بدلًا من | استخدم |
|---|---|
| إدارة الحالة | رصد إشارة الدعم أو قراءة بلاغ الأمان |
| تعيين مختص | عرض توصيات أو خيارات معلنة |
| قبول حالة | جاهزية أو توفر أو عدم توفر |
| رفض حالة | غير متاح أو غير مكتمل أو محظور للسلامة |
| التحكم في جلسة | رصد معلومات الخدمة المعلنة |
| طابور المراجعة | تدفق الإقرارات أو تدفق الرصد |
| غرفة التحكم | غرفة الرصد أو غرفة المالك حسب الوظيفة |
| متابعة علاجية | ملاحظات الاستمرارية أو رصد الاستمرارية |

## قاعدة التحقق

إذا كان المصطلح علاجيًا أو تشغيليًا داخل تقرير أو تحليل:

**LIMITED ALLOW**

إذا تحول إلى اسم إجراء أو سلطة تشغيلية:

**BLOCK**
