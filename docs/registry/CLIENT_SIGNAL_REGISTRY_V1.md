# CLIENT SIGNAL REGISTRY V1

Client is not a record.

Client is a signal source.

The system observes preferred identity,
aspirations,
strengths,
relationships,
support preferences,
and self-expression.

Avoid:

- diagnosis
- weakness-first language
- deficit language
- labeling language

## Identity Signals

Examples:

client.identity.kind_father
client.identity.kind_mother
client.identity.loyal_friend
client.identity.helper
client.identity.loving_person

Purpose:
How the person chooses to define themselves.

---

## Forbidden Signals

negative labels

permanent deficit identities

stigma identities

Examples forbidden:

client.identity.failure

client.identity.broken

client.identity.weak
