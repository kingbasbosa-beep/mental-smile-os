# Mental Smile OS Public Web

This folder contains a lightweight static public website for Mental Smile OS Generation 1.

## Files

- `index.html`
- `showcase.html`
- `chapter.html`
- `contact.html`
- `contact-links.js`
- `styles.css`
- `README.md`
- `PUBLIC_WEB_REPORT_V1.md`

## Purpose

The site presents Mental Smile OS as an Arabic-first mental health discovery and support ecosystem operating foundation.

`showcase.html` provides a styled public web entry into the Generation 1 story, avoiding raw directory or markdown listing behavior for first-time visitors.

`chapter.html` renders each Generation 1 story chapter as a styled public web page instead of exposing raw markdown text to visitors.

`contact.html` is the official public contact gateway for Mental Smile OS. Channel URLs are centralized in `contact-links.js`.

It is public-safe and states that Mental Smile OS is not:

- a clinic
- a therapy provider
- a diagnosis system
- an emergency service
- a platform for booking, payments, or session control
