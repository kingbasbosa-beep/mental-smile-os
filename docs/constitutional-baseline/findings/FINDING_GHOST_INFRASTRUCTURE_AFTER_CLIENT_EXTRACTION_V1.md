# Finding: Ghost Infrastructure After Client Extraction V1

Finding ID: FINDING-GHOST-INFRASTRUCTURE-AFTER-CLIENT-EXTRACTION-V1
Status: ACTIVE_FINDING
Source Operation: OP-PURPOSE-NULL-AUDIT-GHOST-INFRASTRUCTURE-V1

## Finding

After pure client identity hard removal, ghost infrastructure remains in placeholder routes, unproduced signals, unbundled legacy assets, session saved destination storage, and localization residue.

## Evidence

- Several S Capital and public portal routes render placeholder-only surfaces.
- Residential signal types remain in validators/monitoring without active producers.
- Old client dashboard/register assets remain on disk, although no longer bundled.
- `saved_destinations` can be written with `sessionId`, but no caller for `watchSessionDestinations()` was found.

## Risk

The system can look connected while not serving an active journey.
