Runtime effect: none

## Doctrine

Registries are governance indexes, not lists.

A registry makes system relationships visible: ownership, status, consumers, dependencies, classification, and archive state.

## Required Registry Behavior

Each registry should identify:

- governed object
- owner
- consumers
- source evidence
- status
- risk
- archive relationship

## Rules

- A registry does not create runtime.
- A registry does not approve implementation.
- A registry prevents hidden relationships.
- A registry must distinguish active, legacy, archive, evidence, junk, and unknown.
