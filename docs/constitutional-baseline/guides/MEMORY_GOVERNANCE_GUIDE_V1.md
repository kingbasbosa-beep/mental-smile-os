## Doctrine

Memory governs evolution.

Mental Smile OS preserves why decisions happened, how eras changed, what was retired, what was learned, and what must not be repeated.

## Rules

- History is layered, not rewritten.
- A snapshot records a state.
- A card governs an object.
- A registry indexes relationships.
- Archive preserves causality.
