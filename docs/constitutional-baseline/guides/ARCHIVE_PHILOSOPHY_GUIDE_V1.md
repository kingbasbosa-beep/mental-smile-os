# Archive Philosophy Guide V1

Status: ACTIVE_BASELINE_GUIDE
Classification: MISSING_CREATE
Authority: Owner Governance
Runtime effect: none

## Doctrine

Archive is constitutional memory, not trash.

Mental Smile OS does not delete knowledge. It stops using retired material in runtime while preserving the reason, lesson, lineage, and decision that made the material meaningful.

## Rules

- No deletion before archive card.
- Archive evidence before cleanup.
- Evidence, decision, finding, lesson, doctrine, and historical context are not junk.
- Runtime retirement is allowed only after the archive reason is known.
- Generated noise, build output, temporary files, and irrelevant local artifacts may be classified as junk.

## Required Archive Record

Every archive record must identify:

- item
- era
- reason for retirement
- active replacement, if any
- evidence value
- governance risk
- owner decision status
