# Finding Governance Guide V1

Status: ACTIVE_BASELINE_GUIDE
Classification: MISSING_CREATE
Authority: Owner Governance
Runtime effect: none

## Doctrine

Findings are memory material, not bugs.

A finding preserves a discovery, its cause, its evidence, its risk, and the decision needed to prevent future repetition.

## Finding Lifecycle

```text
Finding
-> Card
-> Guide Update
-> Registry Entry
-> Owner Decision
-> Runtime Action, if approved
-> Archive
-> Memory
```

## Rules

- Do not discard findings after a fix.
- Do not treat legacy residue as meaningless.
- Do not perform runtime cleanup before the finding has a classification.
- Unknown findings remain UNKNOWN until evidence is sufficient.
