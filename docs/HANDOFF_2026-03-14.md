# Mental Key — Handoff Report
**Date:** 2026-03-14  
**Project:** mental_key_v2

## Product Identity
Mental Key is a non-medical, non-diagnostic, safety-first psychological support app.
Core principles:
- Non-medical
- Non-diagnostic
- Supportive, calming, awareness-based
- Family-aware
- Safety-first

The AI must never diagnose, prescribe, or act as a replacement for a human clinician.
It can support, de-escalate, detect risk, and escalate to human review when necessary.

### 3. Booking flow
Implemented working flow:
- client sends booking request
- request appears in client "my bookings"
- request appears in admin booking queue
- admin assigns / forwards to clinician
- clinician receives request in inbox
- clinician can accept / reject
- client sees updated status

Statuses used:
- pending_admin
- pending_clinician
- accepted
- rejected

Main pages involved:
- booking page

- admin booking queue page
