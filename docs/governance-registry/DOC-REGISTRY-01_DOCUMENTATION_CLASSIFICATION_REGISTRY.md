# DOC-REGISTRY-01 - DOCUMENTATION_CLASSIFICATION_REGISTRY

## File Path

`docs/governance-registry/DOC-REGISTRY-01_DOCUMENTATION_CLASSIFICATION_REGISTRY.md`

## Executive Summary

Mental Smile Federation needs a Documentation Registry because documents are now part of the operating system. The project contains constitutional reports, execution packages, knowledge blueprints, implementation-era documents, web architecture documents, demo productization documents, gold indexes, and historical transition records.

Without classification, documentation becomes difficult to govern. Active references may conflict with historical references. Transitional documents may be mistaken for current doctrine. Replaced concepts may return as assumptions. Valuable history may be lost because older documents are treated as obsolete instead of archived memory.

This registry classifies documentation by lifecycle, authority, usage, historical value, and source-of-truth role. It does not edit, move, delete, retire, or modify any existing file.

## Documentation Governance Doctrine

Documents are assets.

Documents have lifecycle.

Documents have status.

Documents require classification.

Every important document should be understood by:

- what it is.
- whether it is active.
- whether it is historical.
- whether it has been superseded.
- whether it remains a reference.
- whether it belongs to a transition phase.
- whether it is source of truth.

## Classification Framework

## Active Constitutional Documents

Purpose: define doctrine, authority, institutional boundaries, and no-return decisions.

Usage Rules: used as high-authority references for governance and implementation alignment.

Review Cycle: annual or constitutional review.

Archive Rules: preserve permanently.

## Active Implementation Documents

Purpose: define actual department or operating structures.

Usage Rules: used to operate active implementation-era departments or systems.

Review Cycle: monthly during activation, quarterly after stabilization.

Archive Rules: archive revisions, outcomes, and superseded versions.

## Active Governance Documents

Purpose: define registries, readiness, governance, classification, assets, policies, and health systems.

Usage Rules: used for manual governance and future migration readiness.

Review Cycle: quarterly.

Archive Rules: preserve approved versions and registry changes.

## Historical Documents

Purpose: preserve project history, transitions, and prior reasoning.

Usage Rules: used for context, not as current authority unless confirmed by Source of Truth.

Review Cycle: annual historical integrity review.

Archive Rules: preserve original records.

## Foundational Documents

Purpose: preserve foundation decisions, early architecture, and baseline blueprints.

Usage Rules: used as origin context and supporting reference.

Review Cycle: annual or when doctrine changes.

Archive Rules: preserve permanently.

## Reference Documents

Purpose: support understanding, implementation, planning, or interpretation.

Usage Rules: used as supporting material, not necessarily governing authority.

Review Cycle: as needed.

Archive Rules: preserve while useful.

## Legacy Transitional Documents

Purpose: record transitional states from earlier product, booking, admin, web, or demo eras.

Usage Rules: used for history and migration understanding; not used to override current doctrine.

Review Cycle: annual legacy review.

Archive Rules: preserve and mark clearly.

## Retired Documents

Purpose: preserve documents no longer active or superseded.

Usage Rules: do not use as current guidance unless revalidated.

Review Cycle: archive review only.

Archive Rules: preserve for traceability.

## Future Planning Documents

Purpose: capture planned, future, or not-yet-activated concepts.

Usage Rules: used for roadmap thinking, not current operation.

Review Cycle: quarterly planning review.

Archive Rules: preserve if strategically relevant.

## Transition Conditions

Draft becomes Working when it is being actively shaped for review.

Working becomes Approved when Owner or accepted governance process confirms it.

Approved becomes Active when it is used as a current reference.

Active becomes Historical when superseded but still important for context.

Historical becomes Retired when it should no longer guide current decisions.

Retired becomes Archived when preserved for traceability only.

Archived remains preserved and should not be silently modified.

## Documentation Risk Registry

## Duplicate Documents Risk

Risk: multiple documents describe the same concept without clear hierarchy.

Default Severity: Medium to High.

## Contradictory Documents Risk

Risk: older and newer documents conflict.

Default Severity: High.

## Outdated Documents Risk

Risk: transitional documents are used as current guidance.

Default Severity: High.

## Lost History Risk

Risk: older documents are ignored, deleted, or disconnected from institutional memory.

Default Severity: High.

## Missing Source Of Truth Risk

Risk: users cannot identify the current authoritative reference.

Default Severity: Critical.

## Health Framework

Documentation health is measured through:

### Coverage

Measures whether major waves, departments, registries, and implementation packages are documented.

### Classification

Measures whether documents have clear status and type.

### Traceability

Measures whether documents link to source waves, decisions, dependencies, and outputs.

### Source Of Truth Integrity

Measures whether the hierarchy clearly identifies the current authority.

### Historical Preservation

Measures whether older documents remain preserved without silently rewriting history.

### Documentation Health Score

Documentation Health Score is derived from Coverage, Classification, Traceability, Source Of Truth Integrity, and Historical Preservation.

Suggested scoring:

- 0: unmanaged.
- 1: scattered.
- 2: partially classified.
- 3: operational.
- 4: governed.
- 5: federation ready.

## Final Recommendation

Mental Smile should maintain a governed documentation archive by treating every document as an asset with lifecycle, classification, authority, and historical value.

The recommended operating rule is:

- GOLD_INDEX_01 is the current Source of Truth for previous phases.
- Active implementation documents guide current department structures.
- Historical documents preserve context but do not override current doctrine.
- Legacy documents are preserved, not erased, but must be clearly classified.
- Future updates should create revisions or superseding references instead of silently modifying history.

This keeps the documentation system scalable, traceable, and historically honest without losing context or creating conflicting references.
